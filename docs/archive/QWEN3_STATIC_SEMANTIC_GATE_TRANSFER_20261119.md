# E_l静态语义门控迁移：缓存诊断

完整SADI和后续层改进的主线不变。本轮只复用已有缓存与既有E_l/seed43检测器，检查去掉注意力相关输入是否减少误触发，没有新训练、生成、阈值搜索或500图测试。

当前SADI实现只改最后查询位置的视觉logit；对于固定图像和目标token，E_l由prefill图像位置的hpre语义读出并缓存。因此它不直接受到生成查询位置的注意力增强。原模型使用全部36层E_l，经原scaler、128单隐层MLP；阈值固定为原3200图训练F1选择的0.5655522346496582。原2367测试位置AUROC复现0.8042199451，未重选参数。
