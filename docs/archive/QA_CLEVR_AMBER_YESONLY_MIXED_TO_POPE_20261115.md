# POPE popular Yes-only：域内训练与 CLEVR＋AMBER 混合训练迁移

## 协议与样本

LLaVA-1.5-7B 和 Qwen3-VL-8B 分别训练。主对照有两种训练来源：① POPE popular 的 Yes-only train（**POPE 域内**）；② CLEVR9K 与 AMBER existence 各自的 Yes-only train 合并（**迁移**）。各数据集沿用原图片级 8:2 划分。种子 43/44/45，保持相同的单隐藏层 SAM、原生 SVAR MLP、来源训练集 Real-F1 阈值。SAM=`risk@question_object_pre_token`＋`F_log@prompt_last_token`；SVAR 为物体词前第 5–18 层、448 维。两方案均在同一批 POPE popular Yes-only test 上评估；混合训练方案不使用任何 POPE 样本训练、重新标准化或调阈值。

| 模型 | 混合 train Real/Hall | 混合 test Real/Hall | CLEVR test Real/Hall | AMBER test Real/Hall | POPE all Real/Hall | POPE test Real/Hall |
|---|---:|---:|---:|---:|---:|---:|
| LLaVA | 3009/3203 | 725/834 | 725/739 | 0/95 | 1183/91 | 239/23 |
| Qwen3 | 3494/436 | 834/104 | 834/26 | 0/78 | 1254/94 | 249/24 |

AMBER existence 的 GT 全为 No；Yes-only 样本因此全是 hallucination。混合来源中“来自 AMBER”与负类完全相关，pooled 测试指标可能利用数据集差异。单独 AMBER test 的 AUC/AUPR 不定义。

POPE 上 SAM 的排序仍优于 SVAR，但来源阈值迁移后两个方法都几乎全判 hallucination：LLaVA/SAM 在 all 仅有平均 0.03% 判 real，在 test 也为 0%；其他组合全为 0%。例如种子 43 的 LLaVA/SAM 来源阈值 0.446，AMBER test 平均 real 分数 0.00174、POPE all 0.00613；Qwen3/SAM 来源阈值 0.741，AMBER test 约 1.6×10⁻⁵、POPE all 约 5.8×10⁻⁶。这个现象与模型利用 CLEVR 合成图和自然图像数据集差异的解释一致，但仅凭这些结果不能证明其内部机制。

同一 POPE test 队列上，CLEVR-only → POPE 的 SAM AUC 是 LLaVA 55.60%、Qwen3 64.42%；混合后是 70.21%、67.36%。排序在 LLaVA 有提升，但混合后的来源阈值决策已崩塌。上方的 POPE 域内对照才是本报告所称的“域内效果”。
