# Qwen3 首次物体提及的视觉写入与 FFN 偏离

从新 COCO 500 的 SADI 输出取实际 B16 的全部 19 个批次，共 304 图。保持原设备、批次成员及顺序，因果回放已保存的 token，最多到第 128 个生成位置。逐句分词 CHAIR 的物体字符位置与原生成 token 对齐，在第 18、24、25、28、31 层读取目标词方向上的实际注意力写入、FFN 更新的空间偏好、目标词 FFN 增益、候选排名和视觉注意力总量。层号从 0 开始。诊断只观测，不调整注意力或 FFN。

回放 1707 个位置，所有记录的自由 argmax 均与对应缓存 token 一致。符合单一物体标注的 655 个首次提及中，582 个有真实标注，73 个为幻觉。后续同类提及分别 1017 和 35 个。首提定义为逐图第一次提到 CHAIR 的规范物体类别。诊断仅覆盖本项目的 304 图和最多前 128 个 token，结果用于选特征。

“名词 top8”要求目标 token 在该层整个词表的 top8 内，并通过原 WordNet 实体 token 门控。第 28 层若进一步限制分差至 2 logits，覆盖 248 个真实首次与 26 个幻觉首次。以真实组视觉注意力总量的 20 分位 0.11934 作探索阈值，其中低视觉总量的真实首次 50/248，幻觉首次 13/26。第 28 层 top8 组中，较低视觉总量的全组 AUROC 为 0.718，按规范类别内配对加权为 0.671，类别内有 258 个正负对。第 28 层有符号写入比例的预测方向与先验相反，在 top8 上按类别内比较接近随机，因此没有直接用这个总量指标惩罚目标词。第 24 层的写入与空间偏离联合在按批次隔开的两折预测 AUROC 约 0.667，按类别内比较 0.596。类别构成和候选可见性都会影响这些数字。

由此计划在与诊断图零重合的缓存 100 图比较两种运行时干预。第 28 层视觉注意力总量低于 0.12 时，在 top8、离首选不超过 2 logits 中取第一个实体候选。生成前缀未出现该 token ID 才干预。两组在第 29 层加入相同的视觉 logit 增益，上限 0.5，随视觉总量降低而增大。其中一组加入目标词正向写入和 FFN 空间偏好的差异引导，在相同视觉总权重下向证据缺口重分配。前缀 token 去重不等于 CHAIR 物体类别去重。保留完整 SADI 基底，两个新增方法只生成新描述，基线复用原批次并检查前缀。

下一步优先校验候选在同一因果前缀下是否真的更有视觉支持。当前观察中，低视觉注意力可以定位部分误提风险，但只把视觉权重分给局部读出的近邻名词，未能稳定减少新幻觉类别。后续考虑对同一批候选比较去除实际视觉写入前后的 logit 差，以及 FFN 前后的相对增益，按同类真／假首次提及检查其区分度。
