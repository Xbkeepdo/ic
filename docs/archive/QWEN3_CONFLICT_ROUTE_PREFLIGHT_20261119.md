# 完整SADI后的文本路线抑制：实现预检与100图协议

新候选保持SADI原0-based5–18层，在19–35层加入文本路线抑制。它借用CRG的路线分解和有符号贡献，比较VRI排序与本项目SAR/FFN中间量排序，不称为CRG完整复现。

## 文献与已有实验的区别

[CRG原文](https://arxiv.org/html/2605.24024v1)将头输出分为视觉和文本路线，用梯度近似当前决策对两条路线的影响，并在冲突头中按视觉依赖选择性抑制文本。原文包含两种冲突；本适配只用视觉反对当前目标、文本支持当前目标的Conflict-B。

本仓库此前已试过31层、最多4个头、只抑制生成历史路线，并用0.5+0.5D提高剂量的版本。它未同时改善两项CHAIR，见QWEN3_SAR_EMS_REPEAT_HISTORY_ROUTE_20261118.md。本次覆盖19–35层、非视觉文本路线，测试固定局部系数规则下的头排序；没有把旧失败试验当作新结果。

另阅读[SPIN](https://arxiv.org/html/2505.16411)的低视觉关注头抑制，以及[ASCD](https://arxiv.org/html/2506.14766)的正负注意力分支和离线文本头选择。它们提供不同动作的参考，本轮均未复现。ACD仅核对了[官方摘要](https://proceedings.mlr.press/v306/chen26dx.html)，PDF抓取遇到content-type/验证页限制，不据未读到的全文实现其公式。

## 固定方法

对当前原生最终候选y，在同一native点做一次后层梯度查询，取得19–35层注意力后残差的梯度，再经W_O投影到各头。设原联合softmax为a，视觉位置为V，非视觉为T：

```text
Ovis_h = Σ_(j∈V) a_hj v_hj
Otxt_h = Σ_(j∈T) a_hj v_hj
Δvis_h = <∂log p(y)/∂O_h, Ovis_h>
Δtxt_h = <∂log p(y)/∂O_h, Otxt_h>
B = {h : Δvis_h < 0 and Δtxt_h > 0}
VRI_h = |Δvis_h| / (|Δvis_h| + |Δtxt_h| + 1e−8)
```

VRI对照在B中按VRI从低到高排序。引导版使用自己的分布：

```text
Q_j = Normalize(write_norm_j × (1 + log_s_j(y)))
P_j = softmax(cos(hpre_j, native_FFN_update) / 0.03)
aVis_hj = a_hj / Σ_(k∈V) a_hk
R_h = Σ_j aVis_hj × P_j/(Q_j+P_j)
```

R较大表示该头的视觉偏好更集中在FFN偏好相对目标证据占优的位置。引导版在B中按R从高到低选最多8头，同值时用VRI顺序；错位对照先将R沿32头移动16位再排序。Q=P时R精确为0.5，引导规则恢复VRI。

选中头的文本系数按排名线性从0到0.5，其余系数为1；只有一个头时为0。k=8及该范围是提前固定的工程适配值，未称为Qwen3论文最优参数。三规则在同一个native冲突集上的系数多重集相同；生成分歧后的全程触发次数和总剂量不保证相同。

所有层的选择在一个native点固定，然后重放19–35层。实际动作是`O'_h=O_h+(g_h−1)Otxt_h`，每层使用该层当前重放query的真实文本写入，而非减去旧轨迹的文本向量。注意力不重新归一化；本层视觉注意力权重不受该后置动作改变。后续层的query和视觉注意力可以随前层干预变化。BF16下分块矩阵乘加的舍入误差另记录，不宣称浮点路线和式逐位等于整块乘法。

候选仍限原309词元及生成前缀未出现的词元/物体类别；取消学习得到的108维门控，不按本轮GT选位置。一个batch/step只做一次反向查询，供全部17层共用。只接受最终原目标实际log概率下降的提案，否则恢复hidden及当前20–35层KV，历史KV不改。19层注意力后的动作不改变该层已经计算的当前K/V。
