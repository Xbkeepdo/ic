# 保留完整SADI后的相邻层证据引导：视觉总量匹配开发100图

保留完整SADI、在后续层接入我们的信号是当前主线。新增的总量匹配版本已完成100图、双评估、机制审计和配对数值检查。原生证据版较固定增强的CHAIRi略低，但没有减少任何图像上的幻觉提及或错误规范类别；差别来自分母变化。逐层刷新更弱，空间打乱对照仍有相近分数。本轮不推进新的独立500图，预留样本不消费。

## 设置和方法

Qwen3-VL-8B-Instruct，BF16/eager/greedy，提示Describe this image.，最多512个新token、max batch16。全部层号从0开始：SADI保留5–18层，19层不变；新增模块由19→20、20→21一直到34→35，共16个目标层。不存在两种方法各用一半层的限制。

沿用已使用的开发100图及原22个有序批次。SADI、SVAR和固定增强逐字复用原控制文件，三种新候选各91图现场生成、9图来自7个经验证的完整零正门控批次；两卡均先验证原SADI32token前缀精确一致。这里是开发比较，不是独立测试。

原108维SAM-V2特征门控、阈值0.418672114610672、309个物体首token和首次类别规则不变。目标条件下的写入证据Q及FFN偏好P沿用原构造，P温度0.03，D为两分布的Hellinger平方距离。

令 u_j=D Q_j/(Q_j+P_j)，r_j=2u_j−D。逐头系数为c_hj=sigmoid(r_j+b_h)，用32次二分选择b_h，使当前实际query的视觉分区满足：

`sum_j exp(z_hj + abs(z_hj)*c_hj) = sum_j exp(z_hj + .5*abs(z_hj))`。

非视觉logit不变，系数在[0,1]。匹配发生在各版本自身的实际query上；干预会改变后续query，因此不要求不同版本整条轨迹逐层总量相同。零或常量方向退回固定增强。三版本分别读取原生层状态、实际干预后的前一层状态、或将刷新的patch方向滚动半个视觉区间。原最终候选词的实际log概率下降才接受，否则恢复hidden和当前尾层KV，历史KV不变。

## 分母和原图检查

原生版与固定版的总提及差为+41，四图分别是555298 +63、242368 −17、68198 −3、353411 −2。假提及逐图都未变化，因此这项Ci下降完全来自分母。555298中原生版反复生成真实可见的laptop、keyboard、monitor等，提及从12增至75，仍有1个假标签，不能把这类重复计数视为缓解。

243882中固定、原生和打乱版都删除13次table标签，占原生版相对SADI净少17次标签的76.47%；刷新版仍有13次。各版仍循环，最早干预的book本来真实且token未变。共同去除该图后，SADI/native的Ci为7.00/6.39；这仍不能说明native优于固定，因为两者逐图假提及始终一致。

核查预设队列及全部变化的错误规范类别，共8张原图；7张逐字复用已有JPEG，1张新下载，均核验SHA。检查记录如下，未修改自动分数。

## 实现和开销

三候选的273次现场图像生成、27次证书缓存和双评估耗时927.89秒（15分27.89秒），三项后处理另18.47秒。300份历史控制不计入本次现场生成。

原生/刷新/打乱分别41/38/40次提案、27/24/26次接受，0次反向传播。刷新版570个层记录的预算确有变化，打乱版600个。FP32视觉总量最大误差1.0431e−6，BF16舍入差最大0.0048275，均满足预先规定的容差；不宣称BF16严格守恒。未接受干预的整段输出与SADI精确一致；9图缓存范围也通过审计。

代码保留在features/qwen3_mass_matched_visual.py、features/qwen3_mass_matched_feedback.py，以及scripts/run_qwen3_mass_matched_visual_pilot.py。机制/数值/配对审计均通过，后加的分母核查使用协议已冻结的审计源码。所有原始输出、两种评估器结果、对照和预检证据均保留。分母诊断v2区分表面词与规范类别，保留原v1，不改变任何分数。
