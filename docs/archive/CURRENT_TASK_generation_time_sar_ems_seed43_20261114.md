# 种子 43 的生成时 SAR+EMS 幻觉缓解试验

目标：在 COCO 图片描述生成中探索三种 SAR+EMS 指导方法，并用一个种子先验证幻觉缓解效果。

完成：LLaVA-1.5-7B、Qwen3-VL-8B；种子 43；每模型同一批 400 张测试图；贪心、风险候选重排、风险门控视觉对比、风险回退和普通 beam 对照。验证集各 50 张用于流程检查，触发阈值由既有完整验证集分数确定。两模型所有方法的 400 张输出图片 ID 已逐项核对。

主要结果：LLaVA 贪心 CHAIRs 50.5%，视觉对比 48.25%，回退 48.0%，风险候选重排 49.25%，普通 beam 47.25%；Qwen3 对应 45.0%、43.75%、41.0%、42.75%、41.5%。风险回退在两模型中最好地降低 CHAIRs，且真实物体提及均值近似保持；风险候选重排未超过普通 beam。

详细方法、CHAIRi、配对 95% CI、物体召回、篇幅、耗时及局限见 [完整报告](../../outputs/generation_time_sar_ems_seed43_v2/summary.md)。实现见 [实验脚本](../../scripts/generation_time_sar_ems_seed43.py)。
