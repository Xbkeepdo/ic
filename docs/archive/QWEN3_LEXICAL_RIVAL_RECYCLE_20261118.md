# Qwen3：物体词形触发、视觉支持候选与较早层注意力回收

本轮继续检验原检测信号能否指导 SADI 的生成，复用原开发集100图、保存的 SADI 对照和全部 E_l 缓存。该开发集已多次用于探索，不是独立验证。四项100图实验均已完成并审计；类别首次门控版作为弱信号候选，已固定参数进入一组新的500图独立跟进，尚无500图效果结论。

## 固定设置

Qwen3-VL-8B-Instruct，COCO val2014，`Describe this image.`，greedy、BF16、eager，最多512个新token。沿用旧100图的22个有序批次与GPU分片，最大batch16。SADI仍作用于0-based第5–18层。两张GPU分别处理原分片；所有旧对照按原文件复用，抽批前64个token重新核对。

检测器仍为旧COCO训练得到的 `I+E_l/seed43`，没有重新训练或利用当前标签调整阈值。输入依次为36层I和36层E_l，`p_real<0.5`触发。I在第5–18层读取局部SADI分数修改前的注意力，但实际残差与生成仍为SADI；这不是完整无SADI前向。E_l直接复用每图、每层、每目标token的缓存。

## 1. 收紧到单token物体词形

旧训练目标词表有496个token ID，其中包含 `h`、`fo`、`water`、`can` 等单词片段或其他语境。新词表只保留解码后以空格起始、去掉空格后全部为英文字母、且其名词原形在标准CHAIR单词同义词表内的训练token，共309个。该步骤只读标准词汇和旧训练词表，不读当前图片标注。

这是词形筛选，不包含下一token的词边界确认或当前语境的词性判别，也不覆盖多token物体词。不能称为准确的完整物体识别。

在缓存的SADI输出上，首次训练token候选共441个，其中148个不在CHAIR标注的物体起始位置。新词表保留270个候选，其中20个不在这些起始位置。相应物体位置从293个降至250个，覆盖的幻觉位置从36降至31；不能将“非物体候选减少”解释为保持召回的检测改进。

新词形范围内，原检测器AUROC为0.7774；`p_real<0.5`标出11个幻觉位置和16个真实位置。旧范围对应AUROC0.8008、14个幻觉和18个真实位置。以上是开发集范围诊断，未用于调阈值。

实际干预与上一版空间引导注意力回收相同：在31层用最终原词的概率梯度定位支持该词的历史文本注意力和反对该词的视觉写入；按视觉证据分布与FFN空间偏好的Hellinger偏离，将部分历史注意力分配给相关视觉位置。每头FP32注意力总质量守恒。只保留使原词实际概率下降的提案，否则恢复隐藏状态及32–35层当前KV。

## 2. 显式的视觉支持候选

进一步要求原目标外存在一个可替代的物体词形。候选限于最终分布top16、与原目标logit差不超过2、检测器`p_real>=0.5`，且局部视觉写入支持大于0并高于原目标。按模型原概率选第一个满足条件的词，不使用图像GT。

令原目标为y、候选为z，梯度目标改为最终logit差 `m=logit(y)-logit(z)`。根据该差值的负向视觉写入与FFN偏好构造同类回收方向。三个有界尝试依次回收符合条件的历史注意力的 `0.5D`、`D`、`min(1,2D)`，共享一次梯度。只有最终argmax确实为z且差值减小时才保留；失败后恢复原隐藏状态和当前KV。这里D仍由目标条件视觉分布与FFN空间偏好的偏离决定。

完整100图共有270次词形候选，其中238次未被原检测器判为风险，另外32次没有满足全部条件的可替代词。因此实际提案0次、保留0次，100个输出token序列逐个与SADI完全相同。这是候选筛选无覆盖的结果，不能用于判断实际候选干预有效或无效。

## 3. 将回收位置移到19层

保留第一项的309词形、同一完整I/E_l检测器、阈值与回收比例，把目标条件视觉写入、FFN空间偏好及注意力动作都从31层移到19层。使用最终词概率对19层注意力后残差的梯度，经过19层FFN和20–35层传播。仅重算当前查询，20–35层覆盖当前KV位置；未通过实际概率下降检查的行全部恢复。

这是19层同层调整加当前查询的尾部重算，区别于旧18→19/19→20的单次前向next配方。SADI5–18保留完整，也不是旧“截短SADI加六层指导”的实验。

两图32步预检已经通过：关闭、零调整、强制拒绝的逐步logits和token与SADI精确一致；20–35层全部当前KV也精确一致，36层缓存长度每步只增加一次。强制门控的实提案2次均保留，梯度探测的最终隐藏差值为0。正式实验不强制门控。

实际100图中，CHAIRi升至10.01%，幻觉提及89→120，幻觉类别36→34但重复幻觉53→86。主要增加来自图154497的`bench`，1→38次。该图在第一次出现当前token ID `man` 时已提到人物；对这个真实、重复类别的干预没有立即换词，但改变了后续循环的内容。不能因为两类幻觉被消除而忽略全量提及增加。

## 4. 在已生成前缀中排除出现过的类别

只新增类别首次门控，其他19层操作不变。用已生成文本、标准物体同义词和名词还原识别已经提到的类别；例如`woman`、`man`、`people`、`chef`均对应person。匹配多词别名时先取最长匹配，包含标准`baby elephant`、`passenger train`等短语规则。不使用图像GT，也不读取当前目标后的模型输出。

该门控在缓存SADI前缀上将270个候选减为209个；可标注物体位置191个，其中幻觉29、真实162，`p_real<0.5`仍标出11个幻觉位置，真实误触发16→7。它依然没有确认当前token后是否接单词后缀，也不区分orange的颜色和水果语义，不能称为准确的当前物体词识别。

实际生成272次词形候选中有64次被类别历史阻止，23次干预提案中22次保留，3次立即换词。12张图的完整序列改变。图154497恢复为SADI的原输出，未出现新增的bench循环。实际减少两次提及：图19132的颜色词分词变化，以及图316254将`remote`换为`similar gadget`。查看316254原图，手中设备有翻盖式手机的屏幕和按键；原描述已有mobile phone，再追加remote是一个无依据的替代猜测。另一次立即换词为`man-made`的首token`man`→`heavy machinery`，不是物体幻觉纠正。这些病例说明当前词边界识别仍有缺陷。

31层词形回收共有32次提案，31次保留，3次立即改变原词；12张图的完整token序列改变。相对SADI，幻觉图无增加也无消除，CHAIRi差值−0.047pp，95%图片配对bootstrap区间[−0.286,+0.161]pp；F1差值−0.054pp，召回−0.20pp。

唯一减少的幻觉提及来自图19132：`orange walls`变为`, reddish-orange walls`，是颜色词分词与识别变化，不能视为可靠的物体幻觉纠正。另两次立即替换涉及原本真实的`people`，其中一处变为`trees`；不能以目标概率下降作为词替换正确的证据。第一项不进入500图。

类别首次版相对SADI的CHAIRs持平，CHAIRi差值−0.233pp，95%图片配对bootstrap区间[−0.570,0.000]pp；F1差值+0.163pp，区间[0.000,+0.433]pp，召回持平。重复幻觉提及与SADI同为53次，真实类别同为204，真实总提及1032→1042。因此CHAIRi下降也包含分母增加的作用，不能把全部降幅解释成纠正物体。没有通过原严格筛选中“CHAIRs必须下降”的条件。

## 独立500图跟进（已完成）

固定类别首次版的全部参数，重新比较SADI、该候选、SVAR。候选沿用512-token上限、max batch16；没有在新样本上调参数。新500图seed20261119，SHA256为`faeab5ffd74cfb47536b098a1621806c14176d8a35e2799818d0a9184490fb42`。从40504张val2014中排除6850张已用图后抽样，包含排除全部历史生成与诊断集合。与开发集100图和旧probe compact中3948个有特征的图像ID均零重叠。

这是对弱开发信号的探索性跟进，不是宣称候选已证明有效。进入验证的理由是类别门控避免了一次已识别的误干预循环，保留一例真正的错误物体提及减少，且开发集CHAIRs不增加、CHAIRi较低、F1较高。完整500图用于决定是否保留，开发集不会作为独立验证。

三组均重新生成且实际批次相同；任何一组OOM会丢弃该批三组结果，并共同拆分。原生SADI生成时仅缓存图像的36层E_l，对全部496个旧训练目标一次计算，再供同一实际批次的候选使用。保存的是E_l和逐事件摘要，不保存全层隐藏或patch×全词表矩阵。SADI计时包含这项共享设置，不能作为纯SADI速度基准。

新增语义缓存读取在两张旧预检图上经过16步完整logits与token精确一致检查。首次运行在抽样前因绝对／相对源码路径重复登记触发历史SHA断言，未建立输出集合、未生成新描述。确认原driver已退出后，归一化源码路径重新启动，方法和抽样设置没有变化。失败源码保存于`scripts/experiment_snapshots/qwen3_first_class500_prepare_failure_v1/`。

服务器根目录`outputs/generation_time_evidence_drift_qwen3_fresh_first_class500`。原driver653134/workers653203/653204已结束。完整sentence Cs/Ci/F1：SADI26.60/3.72/73.96，候选24.60/3.43/73.90，SVAR42.40/9.07/76.39。11图修复1新增、幻觉287→256，两CHAIR配对区间低于零，Ci上界接近零。五项完整独立审计通过，无OOM。人工查看发现部分变化受颜色、别名和GT边界影响。完整结果、区间、计时与病例见[独立500图报告](QWEN3_FIRST_CLASS_FRESH500_20261118.md)。

## 验证与产物

四项均已独立核对各300条生成、源码SHA、复制对照、有序批次、两个评估器的聚合、48个配对区间及物体重复／分母。第二项另核对全部270个筛选记录，确认正式实验无诊断强制、无实际动作，100个输出与SADI逐token相同。第四项全部272个前缀判定由独立脚本重算，64个类别阻止和23个提案核对通过。首次单独运行第四项审计时未设置NLTK_DATA而未找到wordnet；明确使用已有缓存目录后，仅重跑失败的CPU审计，生成保持不变。

候选版复用了原回收预检工具；该工具逐case的`diagnostic_force_probe_gate`字段为固定标签，实际由适配器关闭该标志、改用`diagnostic_force_rival=True`构造测试提案。正式实验二者均关闭。预检只证明关闭／零／拒绝的回滚一致性；候选版在两图live预检中也未保留动作，不据此声称保留分支已经得到实测验证。

本机四套快照在`scripts/experiment_snapshots/qwen3_probe_{lexical,grounded_rival,early_recycle,first_class}_pilot/`，均取回冻结源码、全部生成与评分，源码按原manifest逐个SHA核对。服务器四个输出目录后缀为`head-gradient-probe-{lexical,grounded-rival,early-recycle,first-class}-pilot`。新500图入口`scripts/run_qwen3_fresh_first_class500.py`；专门运行时与最终检查脚本`scripts/audit_qwen3_first_class500.py`，完整指标另由原fresh500独立审计核对。

Codex周额度本轮查询为使用12%、剩余88%，未到用户要求的剩余50%停止线。目标保持active。
