# Qwen3 最终候选词与第 31 层视觉写入引导

本轮先检查候选词对齐。第 31 层局部视觉写入移除量在此前诊断中有一定区分能力，但该层首选词经常与最终生成词不同。第 35 层能直接读取最终候选，视觉写入区分能力则较弱。本轮用最终候选词读取第 31 层证据，再调整该层注意力并重算后续当前查询。

## 末层诊断

复用原 304 图的 19 个有序 B16 批次，回放原 SADI 前缀到 128 token 内的 1707 个物体位置。全部原始 argmax 匹配。655 个首次提及包含 582 个真提及和 73 个幻觉。只含独立实体 token 的子集为 543 个，幻觉 55 个。

| FFN 增益 | 0.421 | 0.397 | 0.348 |
| FFN 增益减去视觉移除量 | 0.430 | 0.404 | 0.356 |

正类为幻觉。最终层的实体视觉支持中位数，真实为 0.030、幻觉为 −0.024；FFN 增益中位数分别约 16.99、15.98。655 个首次提及的 FFN 增益都为正，且大于视觉移除量。按“FFN 增益大于视觉支持”无法在这些位置筛选。该末层诊断用于决定读取位置，后续干预仍使用第 31 层的局部量。

服务器诊断目录为 `outputs/qwen3_sadi_terminal_write_trace/`，本机同名快照保留 protocol、全部位置与 analysis。第一次启动遗漏已有 NLTK 资源路径，两个 worker 在生成前退出，修正后完成回放。失败记录保留在目录后缀 `.failed_missing_nltk` 下。

## 干预实现

原 SADI 覆盖 5–18 层，层号从 0 开始。一次常规前向完成后，以最终层首选词作为当前目标。只在已经有 KV 缓存的单 token 解码步骤处理未在生成前缀出现过的实体 token。第 31 层记录其实际注意力与 FFN 状态。

设 $r$ 是 FFN 前残差、$u$ 是 FFN 更新、$a$ 是当前查询收到的视觉写入，$L_y$ 是 FP32 final-RMSNorm 和目标词读出。目标视觉支持为 $V_y=L_y(r)-L_y(r-a)$。只处理 $V_y<0.35$ 的目标。将目标读出局部梯度投到逐视觉位置的实际写入，取负向分量并归一化为 $Q_-$。第 31 层 FFN 更新与各视觉状态的余弦经温度 0.03 的 softmax 得到 $P$。

沿用前次负向写入实验的预算，无新的强度搜索。

$$
b_m=3H^2(Q_-,P)\,\rho_-\,\tanh(0.35-V_y)
\frac{[Q_-(m)-P(m)]_+}{\max_j[Q_-(j)-P(j)]_+},
$$

其中 $\rho_-$ 为负向写入绝对值占全部正负写入绝对值之和的比例。预算通过已有视觉 logits 重分配函数施加于第 31 层，保留其视觉总注意力权重。第 31 层复用已投影的 Q/K/V，重算末查询注意力与 FFN，随后重算 32–35 层的当前查询。对应层的 KV 只替换当前位置中被干预的行，保留此前位置。随后用修正状态正常贪心生成。

该实现先读取最终候选再重算中间层，增加了当前步骤的后层计算。预填充阶段跳过重算。它与此前只将预算传向下一层的实现存在计算流程差异。

## 已有特征缓存的 CPU 检查

复用原 Qwen3 COCO4000 特征缓存，SHA256 为 `0175471b249a6256772511d8de72fb58acd243723891d586d97c6e95e0625184`。保留原图片级 9384/2367 目标划分，以训练图片的三折交叉预测比较四种小输入门控。四组分别为第 31 层 risk/F_log、第 18/21 层 risk/F_log、第 31 层 I/E_l、第 18/21 层 I/E_l。每组使用标准化和 128 单元 MLP，seed 43。以训练集同 token 真假对内的 AUROC 选择输入，仅在选择后查看原测试集。该 COCO 测试集合在此前检测实验中已有结果。

选中 I/E_l 第 31 层。训练交叉预测同 token AUROC 0.723、pooled 0.730；原测试 pooled 0.762、同 token 0.702。在训练交叉预测真实样本的第 95 百分位取阈值 0.4248，原测试真实样本误触发 5.36%、幻觉召回 23.31%。输入只有两个数，覆盖有限。该缓存中的全部图片与本轮 100/500 图都零交集。尚未将该门控用于生成，下一步需要检查它在 SADI 输出上的迁移表现。结果和参数保存在 `scripts/experiment_snapshots/qwen3_small_cached_gate/`。

## 文献记录

Causal Route Gating 使用注意力内视觉与文本路径对目标词的贡献来选择干预。FADE 分析了 FFN 增益与视觉证据之间的关系，并通过降低 FFN 输出进行缓解。本轮实现沿用本项目已有的局部视觉写入移除和 FFN 空间偏好，只新增最终候选词对齐与当前查询尾部重算。[Causal Route Gating](https://arxiv.org/html/2605.24024v1)、[FADE](https://arxiv.org/html/2606.29431v2)
