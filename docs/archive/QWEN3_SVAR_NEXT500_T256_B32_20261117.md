## 实现与固定协议

- Qwen3-VL-8B-Instruct，BF16，eager attention，greedy，prompt=`Describe this image.`；两臂max_new_tokens=256。
- 基础方法严格调用仓库原SVAR实现：零起层5–18，对视觉注意力logit执行`z[h,m] += 0.5 * mean_h(abs(z[h,m]))`。
- 增强通过新`features/qwen3_svar_layer_feedback.py`继承原相邻层反馈，capture内局部替换基础操作为SVAR，退出恢复。旧冻结文件未修改。
- 本层18的Q/P指导注意力19，本层19的新Q/P指导注意力20；strength5，tau0.03，WordNet entity首子词+正FFN gain门控；无直接FFN编辑、无同层重算，也不是旧21/22配方。
- 预算保持`5 * (1-sum(sqrt(Q*P))) * tanh(gain/2) * relu(Q-P) / max(max(relu(Q-P)),1e-6)`，每个来源层重新计算目标与预算。
- 使用上一轮已观察的同500图，ID SHA256为`2df95828676a19b18e9807dd57cc55d3f8ac774f97e0e96454ba14d24cefef26`；没有新抽样。两组均重新生成，采用新的B32分组；不混用旧B16描述作为对照。
- 两卡各250图，按排序IDs stride-2分片、同视觉span和prompt长度分组，最大32，两组有序批次完全一致。共46个batch/方法，其中8个B32覆盖256张，另外244张为较小尾批；无OOM拆分、无Traceback。**不是500张全都在完整32大小批次中生成。**
- 本轮SVAR配对结论适用于本次批次协议；前轮SADI采用B16，跨轮绝对数值同时受到基础方法和批次计划差异影响。
