# Qwen3：目标词视觉写入与 FFN 偏好引导

模型为 Qwen3-VL-8B-Instruct，使用零起第 5–18 层 SADI，第 18→19 和 19→20 层相邻引导。每个源层从 FFN 后的归一化词表 logits 读暂定词，保留实体子词与正 FFN 增益门控。FFN 偏好 $P$ 用 FFN 更新和各视觉位置残差状态的余弦相似度经温度 0.03 的 softmax 得到。

- 原相邻引导的 $Q$ 按各视觉位置实际写入的向量范数乘目标词语义权重形成。预算比例由平方 Hellinger 距离和目标词 FFN 增益决定。位置调整由 $[Q-P]_+$ 给出。
- 双向调整保留 $Q,P$，把位置项改为 $(Q-P)/\max(\max(Q-P)-\min(Q-P),10^{-6})$。正值增加视觉注意力 logits，负值减少。保留每头视觉总权重校正。
- 目标词投影版保留正向调整。设 $a_m$ 是注意力加权并经输出投影后的第 $m$ 个视觉位置写入，$r$ 是末查询 FFN 前残差。令 $g_y=\nabla_r[w_y^\top N(r)]$，用 $Q_m\propto[\langle a_m,g_y\rangle]_+$ 构造目标条件证据。没有正支持时跳过该预算。矩阵运算先将 $g_y$ 乘输出投影，再逐头与 value 点积，数值比对验证与显式物化 $a_m$ 一致。
