# 完整基础方法后的标量视觉指导：开发100图

在旧开发100图上检查：完整保留基础SADI/SVAR的0-based5–18层，后续19–35层加入完整的正交视觉上下文方向。取消负梯度头筛选，每层全部头共用1.4D；D为目标条件视觉写入证据Q与FFN偏好P的Hellinger平方差异。固定对照全部头为1.4。保持原108维SAM-V2门控、词首/首次类范围和阈值不变。只接受原目标实际最终log概率下降的联合回放，其他情况完整回滚。
