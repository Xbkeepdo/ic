状态：完整100图生成、双评估、独立数值／配对区间和质量分析全部通过。P与均匀对照在所有100张上的幻觉对象列表和提及数逐图完全相同，未体现P空间信号的额外纠错收益。本轮候选不推进独立500；旧输出和三臂全部比较保留。

## 方法与比较

Qwen3-VL-8B-Instruct，BF16/eager/greedy、Describe this image.、最多512新token、原开发100图和22个原有序组、max batch16、两张4080 SUPER。该100图已用于多轮探索，不是独立验证。所有层号从0开始；原SADI5–18完整保留。

每步先完成原SADI前向，以最终实际首选token为目标。只在冻结309个COCO物体首token内处理，包含重复词，不用MLP／历史类别过滤，prefill跳过。在源19层读取实际FFN更新u及视觉hpre：

```text
P_j = softmax_j(cos(hpre_j, u19)/0.03)
```

原native路径为正路径。负路径从同一个19层输出出发，重算20–35层当前query。在每层当前状态下，把各头视觉条件注意力的一半换为prior：

```text
A'_hj = .5 A_hj + .5 (sum_visual A_h) R_j   j为视觉位置
A'_hk = A_hk                              k为非视觉位置
```

| 版本 | 固定负分支prior R | 每层eta |
|---|---|---:|
| p_fixed | 原生19层P | 0.5 |
| uniform_fixed | 同长度均匀分布 | 0.5 |
| rolled_fixed | 将同一P沿扁平视觉序列移动floor(M/2) | 0.5 |

各层保留其当前状态下的头内视觉总量，不改变非视觉注意力；后续状态因分支不同而变化，不能称整个分支轨迹的实际总视觉量严格匹配。三者仅改变prior，参数、目标范围、层数和计算方式相同。

```text
z_decode = 2 z_native − z_negative
候选要求 z_native >= max(z_native) + log(0.1)
```

负分支当前KV在返回前恢复，原生路径的历史KV保留，不提交负分支状态。FFN只提供偏好，不修改其激活。源Q_SAR和D仍沿原冻结控制器计算／记录，但固定eta不使用它们；本轮是部分EMS空间偏好的迁移，不是完整SAM或精确OT risk干预。对比路径思想参考前一报告所读ASCD，未复现作者完整头选择或算子。

## 重复、覆盖与原图核查

固定P的去重真实图像类别为200，uniform为202，SADI为204；重复真实提及分别652／800／828。P与uniform的7张文本差异为26611、154497、441840、167273、341094、19132、131063。完整比较已核对，两个新增去重真实类别的原图131063、441840从服务器原COCO JPEG下载，并逐文件SHA匹配。

- **131063**：原图台面有许多洗护瓶。uniform新增bottles的同时进入大量瓶子重复，正确提及3→133，其中新增重复129；不能把这130次提及差当作同等数量的新物体证据。P没有描述这些瓶子，覆盖有损失，但重复显著少于uniform。
- **441840**：原图棒球场后方有停放车辆。P写parked vehicles，uniform写parked cars；后者多一个car标签。该召回差异包含词表覆盖，不等同于P完全遗漏了车辆。

因此F1／召回差异同时包含实际内容覆盖和词形映射。自动评分不改，也不把uniform的重复膨胀包装为更强缓解。

P相对SADI净少18次假提及，前三个减少来源为152336(−6)、369675(−4)、19132(−2)，共12次。预先固定的去前三贡献图诊断中，Ci由SADI5.08827%变为P5.35492%；这是输出相关的敏感性检查，不替换完整100主结果。它进一步说明少量样本与措辞变化对Ci有影响。

旧10图三张原图的核查结论与本轮对应记录相同，因复用对象已逐值核验：353411的固定P确实没有再描述fork，但uniform／rolled对照也可产生相同的删除；575293的seat是沙发部件；377003的躺椅／盆栽词形变化影响计数。本轮没有对P相对SADI的其余全部措辞变化重新作完整物理图像审核；候选已在P与匹配uniform的幻觉对象／计数逐图相同这一比较上未显示增益，不据未审核变化作实物纠错声明。

## 执行与结论

两卡900.33／1,274.74秒（不含模型构建），原图编码10＋12次、共享命中26＋30次。原10候选的两个组均在实际128token及前128事件字典精确匹配后复用，跨旧GPU分片的4图组也通过；实际290份新完整描述、10份旧候选、200份旧基线由runtime_receipt独立核对。三候选逐图事件863／1,015／901，立即换词48／47／46；事件多不等于缓解有效。

从启动到生成完成1,288.15秒(21分28秒)，双评分／独立复算／质量结束总墙钟1,313.73秒(21分54秒)。pipeline、analysis_complete、independent_summary、quality_complete均passed，父与两个worker均已结束；没有本轮分析恢复或生成重试。500份含控制记录、两口径共160个有向配对指标区间独立复算一致。

本机`scripts/experiment_snapshots/qwen3_live_preference_contrast100`取回73个远端产物、11,843,000字节并核SHA，另有原图与复查记录。独立500仍未消费。

本轮不支持把整个P直接作为反事实负路径中的“有害偏好”。下一项低成本机制诊断应把它相对当前目标视觉证据Q的过度偏好`[P−Q]+`与共有支持分开，而不是再增加同一P的层数或强度。需先在固定前缀比较excess、反方向、uniform与错位控制；该构造尚未运行，无效果结论。
