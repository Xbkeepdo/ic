# Qwen3：用实际SADI描述适配信号门控

本轮复用了500张历史SADI描述，在904个符合运行条件的候选位置读取原108维特征，再训练三种子检测器并校准已有模型。所有904个源目标均与当前SADI的条件首选词匹配，但新门控仍未改善开发集上已核实错误的覆盖。两个主候选没有进入生成实验，独立500图未使用。

## 固定设置与数据复用

完整保留本项目SADI的0基5–18层。模型为Qwen3-VL-8B-Instruct，BF16、eager、greedy，提示词为`Describe this image.`。本轮不生成新描述，而是逐token重放已有SADI输出和真实KV，保留其原有62个有序批次，两卡原分片为32／30组，最大batch16。

最初检查的20261116版500图与当前基底源码哈希不符，准备阶段在创建实验根前拒绝，未运行GPU。失败源码和记录已保存。随后采用最近完成、基底代码匹配的`qwen3_causal_visual_tilt_validation500_20261119`中的SADI描述；原实验的SADI确为重新生成。源图与当前开发100图及预留500图均不重合。本轮这些旧500图仅作训练来源，不能当作新候选的独立效果测试。

候选沿用309个词首token、token此前未出现、类别未在已生成前缀中出现的规则。使用sentence修正分词CHAIR和实际响应token的字符偏移对齐标签。904个有唯一自动标签的候选分布在441张图中，包含798个真实、106个幻觉；另61个无唯一对齐标签的候选不进入训练。图像先按ID排序，再用default_rng43划分400／100，其中有可用目标的图像分别为349／92张。

每个目标读取36层risk、36层I和36层E_l，共108维。risk保持K=32、tau=0.03，cost与两端点惩罚系数均为1；I为实际视觉写入范数，E_l使用final-norm视觉hpre的完整词表概率。没有提取F_log。图像语义概率每图每层计算一次，输出头仅在指定目标步读取当前首选词。

## 重放与恢复

两个原B16预检批次共70个目标，全部首选词匹配。正式读取保存808个目标后，脚本因将空候选批次视为错误而停止；原目录、代码和失败信息保留。恢复版本只修正已完成批次复用和空批次处理，数值计算代码段保持逐字相同，训练和诊断版本也仅变更来源路径。

恢复时按哈希复用45个完整批次；只计算剩余13个有目标批次，4个空批次记录为空，不调用模型。预检两批也按字节复用。最终62组全部核查通过，904／904个目标与当前SADI首选词匹配，无目标因不匹配而剔除。全部源特征有限、行身份完整、模型输入哈希一致。

源特征SHA256：`3e99fea5a06fa5c1df6d24dd37e99e5dc86eb517aec7d84f6c1ba93dc21f5745`。恢复协议SHA256：`68fe94b72bb7f3306df036d1afccc329258eb2b0e07715b48fc2647376510ecc`。

## 训练与校准

沿用128维单隐藏层、无BatchNorm、dropout0.3、batch256、drop_last、原学习率与权重衰减、最多100epochs、仅训练部分标准化、最低训练损失选择checkpoint。三种子43／44／45均报告，43为固定主种子。715个训练目标包含633真实、82幻觉；189个校准部分目标包含165真实、24幻觉。drop_last后每epoch使用两个完整batch。源训练中fork有3真实／1幻觉，table有28／5，book有3／0。

触发阈值为165个源校准真实目标分数的第5百分位数，使用linear插值。这个子集用于校准，不作为独立阈值效果测试。同时用相同池重校准原108门控、此前4000源重训的seed43、此前词内平衡seed43，其权重和标准化保持不变。校准后才读取当前开发位置的分数。三新模型源校准部分的AUC分别为83.64%、82.80%、82.70%，最佳epoch为67／48／59，实际训练77／58／69epochs。

## 覆盖与图像核查

已核实的353411叉子／勺子错误仍被漏掉。新43／44／45的真实概率为0.932243／0.935809／0.984467，均高于各自阈值。原模型分数保持0.321520，但改用新源校准后阈值降到0.094299，同样漏掉该错误。

主43新增8个触发位置，全部已有自动真实标签；分别涉及person、books、bed、ball、sandwich、table、另一处ball及dog。这里没有独立断言每个实例的物理真假，但没有新增自动幻觉覆盖或经图像确认的错误对象。原模型仅改校准没有新增触发。

辅助的4000源模型新增标出377003的小圆桌。重新查看原图，小圆桌清楚位于皮扶手椅与灰色沙发之间，不能把其自动幻觉标签当作缺失物体。其他新增辅助标记涉及orange颜色措辞、此前记录的bear／玩具指代，未对齐位置包括man-made和ponytail，未形成新的缺失物体证据。

两个主候选均未满足预先记录的推进条件：保留已核实fork且减少真实误触发，或新增图像确认的错误对象覆盖且真实误触发不超过17。100图入口已准备但未执行。当前诊断没有新的CHAIRs、CHAIRi、召回或F1结果。

## 判断与下一步

此前核查表明，旧raw描述的目标词不总是开启SADI后的首选词。本轮使用真正SADI描述、并核对全部目标匹配后，所测试的适配仍未改善关键错误覆盖。源策略错配可能是一个因素，但这轮结果不足以将门控问题归结于它，也不支持继续盲目重训同一MLP。新源样本较小、词内覆盖有限，同样影响了这次适配，不能据此否定原检测方法的全部用途。

下一方向保留完整SADI，让原信号决定何时需要重新检查视觉来源，并优先检验能否恢复更具体的视觉证据。例如用目标条件写入分布定位区域，仅在后续注意力中尝试更细区域读出，而FFN偏离提供辅助触发信息。先核对少量既有前缀上的实际物体替换和零干预等价性，再决定是否进行100图实验；这是待验证方案，没有缓解结果。

补查的文献提供了不同位置的思路：[Focus Matters](https://arxiv.org/html/2604.03556)研究视觉编码器中的低注意力value替换，其位置不等于本项目后续decoder层；[SDPR](https://arxiv.org/html/2607.16841v2)考虑注意力重分配和视觉key缓存校准；[视觉依据引导的头抑制](https://aclanthology.org/2026.aacl-long.152.pdf)通过区域遮挡识别视觉头，但[作者仓库](https://github.com/raymondsim/grounding-hallucination-heads)目前仅有论文和待发布说明，未提供可直接复用的实现或头排序。本轮没有声称复现这些方法。
