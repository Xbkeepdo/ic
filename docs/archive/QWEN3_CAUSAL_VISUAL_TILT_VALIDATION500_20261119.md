# 原108门控＋固定后层增强：独立500图验证

完整500图上，增强版相对SADI的两项CHAIR平均值下降，物体召回和F1下降。配对区间尚不能确认CHAIR增益；原图核查发现，大部分较大的标签减少来自词义、否定和重复描述。保留此版本作组件参考，本轮不据此宣布稳定的缓解效果。

## 方法、样本和推理

Qwen3-VL-8B-Instruct，BF16/eager/greedy，`Describe this image.`，最多512个新token，最大batch16。三组在相同图像及完整有序批次上分别重新生成，无生成结果复用、自动拆批或中途参数修改。

全部层号从0开始。SADI完整保留5–18层；19层为不变锚点，新增干预作用20–35，共16层。使用原108维risk＋I＋E_l检测器、阈值0.418672114610672、309个物体首token和首次类别规则。触发后，在实际目标层query上将视觉logit增加0.5倍其绝对值，gamma=1；原目标词最终log概率下降才接受，否则恢复hidden和当前20–35层KV，历史KV不动。

这项候选使用我们的检测特征决定何时增强，空间系数统一为0.5。它不是Q/P定向预算或逐层刷新预算有效性的证据。
