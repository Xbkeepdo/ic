# 完整SADI之后的ACG方向与SAR/FFN指导

上一轮第19层质量转移没有降低CHAIRs，且部分CHAIRi变化来自真实物体重复。本轮保留SADI第5–18层，改在第31层调整注意力输出，比较固定强度的对比方向与信号指导方向。层号从0开始。旧开发100图、相同22个有序批次、max batch16、greedy/BF16/eager、提示词Describe this image.、最多512新token。旧5组结果直接复用，本轮只生成两个新版本。

## 借鉴与适配范围

[ACG原文](https://arxiv.org/html/2601.13707v2)使用同一组Q/K/V得到包含图像和屏蔽视觉键的两个注意力输出，并去掉两者差值中平行于屏蔽路径的部分。本轮借用该方向构造，在每头实施正交化。

`d_h = (O_cond,h - O_mask,h) - <O_cond,h-O_mask,h,u_h> u_h`，其中u_h为屏蔽路径输出的单位方向。修改为`O'_h=O_cond,h+gamma_h d_h`，随后执行原输出投影和FFN。屏蔽路径仍包含已有视觉上下文，不等同于完整无图像前向。此处修改输出向量，不是非负注意力概率转移。

两组都是SADI之后、SAM门控、第31层、实际目标概率下降才接受的ACG适配；不称为原论文全层ACG复现。gamma上限固定1.4，取原文Qwen-VL设置作为实验前起点，不声称它适合或最优于Qwen3。

## 我们的信号

共同门控沿用原108维SAM-V2：输入36层risk、I、E_l，真实概率小于旧域5%真实分位阈值0.418672114610672。当前目标为原生最终argmax，候选须是309词首词表内此前未生成的token，且物体类别未出现在已生成前缀。risk仍为原K32、tau0.03、cost及两端点惩罚系数1的精确EMD。没有用当前图像GT选点或调整阈值。

固定对照所有头gamma_h=1.4。指导版读取第31层实际视觉写入范数及原log语义项，构造SAR分布：`Q_j=Normalize(||W_j||*(1+log_s_j))`。FFN偏好为`P_j=softmax(cos(u_FFN,hpre_j)/0.03)`，漂移为`D=1-sum sqrt(Q_j P_j)`。

对原目标最终log概率求一次31层FFN及32–35层反向传播，得到注意力后残差梯度g。对每头上述方向的局部效应为`e_h=(g^T W_O,h) d_h`。定义`beta_h=relu(-e_h)/max_heads relu(-e_h)`，所有负向效应为零时不动作；`gamma_h=1.4 D beta_h`。因此只放大一阶效应会降低当前风险目标的视觉对比头，强度由目标条件视觉写入与FFN偏离控制。它是局部提案，仍须检查重算后的实际概率。

两组接受条件相同：原目标实际最终log概率严格下降，否则恢复原hidden及第32–35层当前KV。第31层复用Q/K/V，full batch重算当前查询，prefix KV保持。固定对照不需要梯度；指导版每个选中步骤一次反传。条件上下文在预算与重算间复用，不重复计算。两组共享图像静态309语义缓存，首次复用逐值核对hpre/value；生成后显式回收owner-reader环。

## 验证与预定筛选

CPU对独立条件/屏蔽注意力逐值核对；正交误差1.19e-7，SAR公式、非正一阶预测、全局梯度尺度不变、零漂移和零/正效应无动作均通过。首次GPU预检在继承的零预算诊断中识别到形状分支错误，未启动100图；v1日志、请求及源码保留。修正版显式委派原注意力零重算，CPU_v2再次通过。GPU preflight_v2通过：B2/32token，关闭、零强度、零重算及强拒绝两臂的输出与全部36层当前KV精确同SADI；每生成encoder1。live固定版3提案2保留、指导版2提案2保留，指导梯度重放hidden最大差0，静态复用命中72。

完整100需两种评估器、独立聚合及配对bootstrap、类历史/门控/头权重/接受/回滚审计、分母和原图复核。相对SADI两CHAIR及错误提及应下降，F1损失不超过1.5个百分点、召回损失不超过2个百分点，移除最大减错图后CHAIRi不变差，并有真实身份纠正；指导版还需优于固定适配。通过后才做头选择对照、适配范围消融和独立500图。
