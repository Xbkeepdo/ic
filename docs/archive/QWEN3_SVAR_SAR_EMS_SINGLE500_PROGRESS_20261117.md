# Qwen3 SVAR＋SAR/EMS 单图实验：阶段汇报

本实验固定原 500 张 COCO 图，Qwen3-VL-8B-Instruct、BF16、greedy、最多 512 新 token、`Describe this image.`，batch size 1，两卡各 250 图。比较 SVAR 与 SVAR＋SAR/EMS 后层注意力。

阶段集按运行前固定的生成清单（图片 ID 升序）取前 N 张，必须两种方法都完成才评分。它不同于此前按种子 43 原始抽样顺序定义的前 N 张，阶段表不能与旧随机前 N 图直接比较。最终 500 张图片完全相同；实验已全部结束，原随机顺序嵌套统计与敏感性分析见[最终报告](QWEN3_SVAR_SAR_EMS_SINGLE500_20261117.md)。
