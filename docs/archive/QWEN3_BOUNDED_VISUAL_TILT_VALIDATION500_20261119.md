# 有界视觉注意力增强：独立500图验证结果

生成、两版评估、四项CPU检查和39张预定原图核查均已完成。两种信号版的自动CHAIRs均低于SADI，但CHAIRi仍高于SVAR，固定增强的CHAIRs和F1也略好于信号版。当前候选未达到预定目标，保留为完整实验记录，继续探索。

## 实验设置

Qwen3-VL-8B-Instruct；500张COCO val2014图像；提示词 `Describe this image.`；最大512个新token；BF16、eager attention、greedy decoding；两张4080 SUPER 32GB；最大batch=16。图像按ID排序后stride2分卡，按相同视觉长度组成批次。五种方法在各批采用相同图像、顺序和实际批量大小，全部重新生成，无caption复用。

500图在读取开发100图指标前预留，seed=2026111901，NumPy PCG64；从31,141图池抽取，按96项历史来源排除9,363图，与开发100、前次500、COCO4000及其他已枚举历史样本不交。这里的独立指项目实验记录中的样本不重叠。样本SHA：`d73949e437e1e8c463992436525602a39e743524ddd5f544ebccd643c0872d01`。本次结果未用于调整这批运行的候选、参数、层、长度或图像。

保留本项目SADI的完整基础干预层0-based 5–18，新增操作位于19–35层。各层预算在同一个原生前向点计算，再联合回放后续层，不是在前层修改后逐层重算预算。

对目标词y，Q=Norm(write_norm × (1+log_s(y)))，P=softmax(cos(u_FFN,hpre_visual)/0.03)，D=1−Σsqrt(QP)，限制到[0,1]。视觉注意力logit增量为 abs(z) × c：固定版c=0.5，漂移版c=0.5D，证据版c=DQ/(Q+P)，gamma=1。该非负视觉增强形式借鉴CAI式5；门控、证据/偏好信号和后续层实现为本项目适配，并非原版CAI复现。

沿用原108维SAM-V2门控，real阈值0.418672114610672，309词首token及首次类别范围；risk K=32、tau=0.03、cost与两个端点惩罚系数均为1。复用实际native context及RAM图像语义缓存，只接受使原目标实际最终log概率下降的提案；拒绝时恢复hidden及当前20–35层KV。无反向传播或额外视觉编码器前向。此处signal_guided=False仅表示未采用梯度，不表示未使用Q/P/D信号。

## 结论与产物

当前两种信号用法未达到两项CHAIR同时优于SVAR的目标，也没有显示出相对固定增强的稳定优势。保留全部正负结果；不把共同未达上限子集、标签词义变化或洗手池漏标样本作为主要成功证据。后续探索需继续检查目标词是否代表当前图像实体，以及原生轨迹上计算的预算如何作用于修改后的后续层。
