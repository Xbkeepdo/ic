# 完整SADI后的17层联合ACG与信号指导

上一轮单层31适配没有确认物体身份纠正。本轮保持完整SADI第5–18层，比较第19–35层的联合提案，以隔离干预范围的影响。层号从0开始。仍用旧开发100图、原22个有序组、max batch16、BF16/eager/greedy、Describe this image.和512新token上限。七组既有描述包括单层固定/指导版，全部直接复用；只生成两个多层新版本。旧开发结果用于探索，不作为独立验证。

## 方法和计算复用

两版共享原108维SAM-V2检测门控、旧域校准阈值0.418672114610672，以及词首/首次类别规则。目标为原生最终argmax。risk仍用K32、tau0.03、cos cost和两端点惩罚系数1的精确EMD。没有使用当前图像GT选点或重训。

各层ACG方向沿用[原文](https://arxiv.org/html/2601.13707v2)的含图与屏蔽视觉注意力输出差，逐头去掉平行屏蔽路径输出的分量。固定版每层每头gamma=1.4。指导版每层仍用`Q=Norm(||W_j||*(1+log_s_j))`、`P=softmax(cos(u_FFN,hpre_j)/.03)`及Hellinger漂移D；对原目标最终log概率的注意力后残差梯度g，计算每头方向效应e，再用`gamma_h=1.4 D relu(-e_h)/max_heads relu(-e_h)`确定尺度。无负效应的层不动作。

17层方向、预算及梯度都在同一个原生解码点计算，一次19层FFN和20–35层反传得到全部梯度。联合回放时，第19层复用Q/K/V与原条件上下文，第20–35层根据修改后的当前隐藏状态重新计算当前查询及Q/K/V，并加入各层预定方向。过去KV不变，full batch和未选行保留。后续预算没有重新估计；这是局部联合提案。仅当原目标实际最终log概率下降时保留，否则恢复原hidden和第20–35层当前KV。

特征计算本来就得到每层每视觉位置的写入范数，因此短作用域拦截原函数，严格核对36层顺序与权重地址，把需要的17层范数复用给SAR，不再额外投影或求OT。原108维特征逐值不变。图像语义缓存按组共享，hpre和GQA值的校验副本放在主机RAM，首次复用逐值检查；没有将隐藏或注意力张量保存到磁盘。避免17份扩展视觉前缀缓存和17份常驻FP32输出投影，每次生成后回收无用引用。

新记录包括原生top2值间隔、目标log概率、提议argmax、实际换词、每层头尺度/效应、联合一阶预测及实际接受。概率下降与物体纠错分开检查。

## 实现检查

## 图像和事件核查

353411图像及COCO框均支持勺子、不支持叉子。两联合版都删除了SADI的错误叉子提及；但事件表明，第一次接受发生在更早的真实“sandwich”上，指导版将其改成“partially”，随后生成轨迹才不再提叉子。这是间接消错，且出现语法问题，不能写成模型直接识别叉子错误或将叉子改为勺子。

555298中指导版确实把当前候选“mouse”改为“smartphone”，照片也有手机，但无法确认鼠标不存在，不能将其计为已确认的缺失物体纠正。243882的错误table重复仍为SADI13次、固定18次、指导14次。224509等图的orange是颜色，404464的ski修饰场所，这些自动计数变化不能充当物体消错证据。

召回损失来自47121的bowl→dish和68198的bicycle→tricycle：仍在描述同一个可见物体，类别词表匹配丢失，不能直接说成删除了可见物体。9张核查原图及其SHA与事件读数一起保存。已确认的叉子消除支持继续验证，但不能据此宣称门控已准确定位错误身份。

## 下一项固定对照和计算复用

## 预定判定

终局后独立核对全部门控/类前缀、17层尺度闭式、联合预测、实际接受/argmax、原生前缀及每批唯一阳性步骤与反传次数。另重算两评估器全部聚合和5000次图片配对区间，检查真实/错误重复与原图身份。

对SADI两CHAIR和错误提及均需下降，F1损失不超过1.5个百分点、召回损失不超过2个百分点，移除最大减错图后CHAIRi不差，且有确认的物体身份纠正；指导版还需优于固定适配。满足后再做头尺度置换、新样本和独立500图。没有依据当前生成结果调整gamma、门控或层集合。
