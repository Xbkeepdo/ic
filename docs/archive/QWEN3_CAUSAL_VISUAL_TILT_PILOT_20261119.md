# 完整 SADI 后的相邻层视觉注意力干预：开发100图

这轮保留完整 SADI，在后续层加入我们的模块。原生预算和逐层刷新预算相对 SADI 的平均指标略有改善，但弱于使用相同门控的固定增强。原图核查没有发现逐层刷新带来额外明确的物体纠正。固定增强保留为需要独立500图验证的组件候选。

此处100图是反复使用的开发集，不是新的独立测试。下文完整报告五组，不用输出定义的子集替代全量结果。

## 方法和设置

Qwen3-VL-8B-Instruct，BF16、eager、greedy，提示词 `Describe this image.`，最多512个新token，最大batch16。原有图像和实际同尺寸批次顺序保持一致，SADI/SVAR直接复用同图同批已有输出，并在两卡分别核对native32前缀。三候选各91张现场生成、9张复用原108门控整批无正触发的证书缓存。无正门控输出复用，无自动OOM拆批。

所有层号均从0开始：SADI完整作用于5–18；19层为不变锚点。新增模块按19→20、20→21、…、34→35指导，共16个目标层20–35。论文从1开始编号时，SADI为6–19、锚点20、新增干预21–36。不是把SADI和我们的模块各分一半，也不是把第18层的同一预算反复用于所有后续层。

原108维SAM-V2门控、阈值0.418672114610672、309个物体词首token及首次类别规则不变。固定增强也使用我们的原特征门控，因此不是无特征控制。对同一最终原生目标词，源层定义

\[
Q=\operatorname{Norm}(\|\mathrm{attention\ write}\|\,(1+\log s)),\quad
P=\operatorname{softmax}(\cos(u_{\mathrm{FFN}},h_{\mathrm{pre,vis}})/0.03),\quad
D=1-\sum_j\sqrt{Q_jP_j}.
\]

固定增强取所有patch的系数c=0.5；两种证据预算取c_j=D Q_j/(Q_j+P_j)，强度gamma=1。目标层视觉logit增加abs(z_j)c_j，z来自实际回放query。原生版的Q/P来自原生源层；刷新版在前一层修改后，用其实际注意力写入和实际FFN输出重算Q/P，再指导下一层。三组使用相同算子及层范围。

最终原目标词log概率下降才接受，否则回滚当前20–35层KV和hidden；历史KV不动。图像hpre/GQA/语义缓存只在RAM复用；无backward或额外视觉编码。sentence为主评估，legacy同时保留。
