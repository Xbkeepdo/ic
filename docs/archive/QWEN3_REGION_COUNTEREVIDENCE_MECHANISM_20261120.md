# Qwen3：区域重读、可靠性与反证注意力

本轮在两张已复核开发图像的六个固定生成位置上完成96次机制试验。保留完整SADI后，直接替换更细区域的视觉记忆没有改变首选词；屏蔽语义不稳定区域也没有改变首选词。反方向增强其中一个区域后，错误的`fork`首选变为词片段`nap`，原词对数概率下降1.3074。错位区域没有产生这个变化。

这给出了一个可以进入生成验证的候选，尚无新的完整描述、CHAIR或F1结果。`nap`只是token片段，不能直接称为已经生成正确的napkin描述。100图生成控制器仍待实现，独立500图未使用。

## 设置

Qwen3-VL-8B-Instruct，BF16、eager、greedy，完整SADI作用于0基5–18层。重放当前开发100图中的两个原有序批次，实际B/P为6/206和4/314。选择243882的person、book、table，以及353411的sandwich、fork、person，合计六个已存词首候选。输入原SADI描述前缀，保留真实KV，全部干预后回滚，再继续同一原始轨迹。

目标风险分数复用原108维SAM-V2在同一不变前缀上的缓存，阈值0.418672114610672不变。book、sandwich、fork及353411的person通过该门控；243882的person和table未通过。所有六个位置都做强制机制试验，但未通过门控的位置不能算作在线方法会触发的修改。

前两轮分别比较完整SAR与语义增量定位、证据与空间错位区域，以及有／无可靠性验证。所有预定策略都保留，没有只报告发生换词的版本。

第一轮读取层19的视觉写入范数与语义项，构造`Q=Norm(norm(write_j)*(1+log_s_j))`，语义增量版本为`Norm(norm(write_j)*log_s_j)`。前者的峰值在叉子案例中落到玻璃杯，后者也未覆盖器具。利用已保存的两种Q之比可还原log_s的峰值位置：`Q_sem/Q_full`正比于`log_s/(1+log_s)`，无需再运行模型。该位置落在薯条区域。

## 细区域可靠性

第二轮选择完整SAR峰值，或当前类别别名概率之和的峰值。类别概率来自层19视觉hpre经final norm和完整词表softmax，不输入图像标注。每个峰值取3×3个合并视觉patch，按原图坐标裁剪并放大至448×448。

缓存原图视觉编码及全部DeepStack输出，把细区域表示映回原ROI，使用原始完整B/P提示重建视觉前缀。保持原图token数量、位置和其余图像不变。使用相同的整图M长度、64位置分块和log1p/expm1运算读取粗／细区域类别概率，避免只投影9个ROI位置引入BF16矩阵形状差异。零替换时两种概率逐值一致。

记ROI平均类别概率为p_coarse、p_fine，可靠性缺口为：

`r = max(0, p_coarse - p_fine) / max(p_coarse + p_fine, 1e-30)`。

FFN偏好使用`P=softmax(cos(hpre_visual19, update_FFN19)/0.03)`，与完整SAR的Q计算`D=clamp(1-sum(sqrt(QP)),0,1)`。区域调整强度固定为`5Dr`，不做可靠性验证时为`5D`。

衰减版本从ROI的视觉logits减去该强度，随后修正视觉logsumexp以保持各头视觉注意力总量；非视觉logits不变。动作作用20–35层的当前查询，不修改FFN激活。

## 衰减与增强的区别

叉子案例的语义峰值位于薯条。更细读出将当前fork类别的平均概率从约6.60e-6降到2.68e-7，得到r=0.9221。但压低该区域注意力后，原fork对数概率反而增加0.4241。这表明该区域当前的value具有净反证作用，不能仅凭语义支持下降就将其屏蔽。

第三轮复用第二轮的ROI、D、粗／细概率和风险分数，仅将注意力调整方向改为增强。没有重复区域编码或更细前缀重建；新运行的原生目标及其对数概率与缓存精确一致。

| 叉子位置的策略 | 原词logp变化 | 新首选词片段 | 是否通过原风险门控 |
|---|---:|---|---|
| 完整SAR区域，验证后增强 | -0.0698 | fork | 是 |
| 语义峰值区域，验证后增强 | -1.3074 | nap | 是 |
| 语义峰值区域，不验证增强 | -1.3298 | nap | 是 |
| 同样验证预算，增强错位区域 | +0.0012 | fork | 是 |

同图真实sandwich的概率上升且首选保持，book和另一person的首选也保持。243882的person在验证增强中变为close，但其风险门控为负，因此在线策略不会在该位置执行这一修改。错误table的门控也为负，本轮不能宣称覆盖了它。

有验证和无验证增强都改变了同一个fork案例，因此当前证据支持继续测试区域选择与调整方向，尚不能证明细区域验证的必要性。该候选也没有证明所构造的可靠性缺口等价于物体真假。

## 实现检查与成本

三轮均通过关闭强度后的逐值隐藏状态／logits检查、36层缓存回滚检查、未选择行保持检查。更细前缀重建采用原始完整B/P，并核对36层提示KV；原图编码结果直接复用。非零注意力操作的FP32视觉质量相对误差小于1e-5，之后仍按原生BF16计算attention×V。

第一轮两GPU worker耗时8.30／15.65秒，实际原图编码各1次，区域编码6／8次；第二轮7.27／14.33秒，区域编码5／6次；第三轮5.55／14.94秒，每卡只编码原图1次，区域编码和更细前缀重建均为0。三轮各自含加载的管线墙钟约29秒，worker纯执行时间不含模型加载。峰值已分配显存约18.6GB。没有保存hidden、attention大数组或完整词表logits；保留标量、少量Q/P向量和ROI图像。

## 下一步：真实生成100图

已将设置保存到`qwen3_region_probe_analysis_20261120/caption_pilot_recipe.json`，SHA256为`e842e8f4dbe5a509370fa72aed41a89fee86f2d21f100c5cfdc696ee451bf4b2`。沿用原开发100图、22个有序批次、maxB16、cap512、相同提示和完整SADI。比较验证增强、无验证增强、验证预算的空间错位增强，并复用SADI和SVAR冻结对照。该100图已被反复用于开发，不能当作独立验证。

实际生成仍须逐步计算原108维门控，不能把固定前缀的缓存分数用于已经改变的轨迹。只接受原目标最终logp下降且argmax改变的提案。先完成关闭、零强度、强制拒绝的tokens/logits/全部36层KV等价性，以及真实接受分支测试，再启动100图。

实现时应在同一原生前向点上评估所有batch行，全部提案结束后才提交接受行。原型每次回滚，生产控制器需要记录回放得到的当前KV20–35，只提交接受行；过去视觉与文本KV不变，缓存长度不额外增加。若提前提交某行再试另一行，会破坏其他行的原生参照。

原图视觉与DeepStack按批次缓存，区域编码与细前缀类别概率按ROI缓存。所有嵌套重建和回放都必须暂停生成回调及特征采集，保留原生19层anchor和20层kwargs。只有相同B/P、视觉hpre、GQA value及模型权重标识完全一致时才跨策略复用图像静态缓存。

完整100图须报告两版评估器、两项CHAIR、召回、F1及配对区间，复核新增／消除幻觉和召回损失。只有实际描述中出现有价值的物体纠错，才进入预留独立500；500中候选、SADI、SVAR都按同49个显式批次重新生成。
