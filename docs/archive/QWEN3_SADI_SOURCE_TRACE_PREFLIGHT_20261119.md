# Qwen3：完整 SADI 的源特征读取预检

主线保留 SADI 的完整层段 5–18（从 0 开始），再在后续层加入我们的引导。截短 SADI 的实验单独保留为消融，不用它代替完整 SADI。本轮检查诊断探针能否使用与实际 SADI 推理一致的源特征；没有新的幻觉缓解指标。

## 旧语义缓存的边界

旧源数据包含 3,948 张有物体目标的图像、11,751 个目标位置。其原始图片划分、生成文本、目标 token、位置和标签均已核对，并与当前开发 100 图、预留独立 500 图互不重合。

缓存构建 v1 将旧字段 target_log_s 误读为原始 L，独立恒等式检查未通过。该版本的代码、协议、失败记录和未验证部分缓存已保留。v2 使用保存的概率重建 L=log(1+Vp)，再验证归一化后的 attention×L 与旧 OT 目标一致，最大误差 3.5763×10⁻⁷；概率求和与 E_l 的最大误差为 1.90735×10⁻⁶。v2 证明了对旧记录的重建正确，不代表能直接复用于新的原生推理状态。

## 整段读取没有通过预检

固定的 8 张源图、31 个目标位置比较了整段 teacher forcing 与逐 token、真实 KV 缓存的 SADI。整段读取对 prompt 最后一个位置及其后的每个 query 应用同一 SADI 规则，保留此前图像和 prompt 的 query。

逐 query 规则的 CPU 张量测试精确通过；同形状下关闭采集、关闭 SADI 的对照也精确通过。首张固定源图上，last-query 采集器与项目原 SADI 控制器的所有强制生成步骤输出精确一致。但是整段与逐 token 的最大 risk 差为 0.46299，I 的最大相对差为 65.02%，原 108 维探针输出最大差为 0.19652，均超出预设限值。8 张图均未通过整段读取的准入检查。

另在预先固定的首图 542145 上，关闭 SADI，保持图像、提示和模型不变，仅比较三种输入长度。prompt 长度为 206，分别附加 0、140、321 个源回答 token。相对仅 prompt 的读取，后两种输入从第 1 层开始已有视觉 hpre 数值差异；第一处的相对 L2 差分别为 0.002658 和 0.002909。相对旧缓存的全层 log_s 最大差分别为 5.1651、1.3778、4.2940。这个诊断说明，在当前 BF16 eager 执行中，改变输入长度会改变部分数值结果；它不是三种缓解方法的效果比较，也没有证明差异只有一个原因。

因此，不放宽原预检容差，也不把整段 teacher forcing 或旧空间语义缓存用于本轮源适配。

## 原生逐 token 采集通过

新的采集方式复用原文本和目标位置，逐 token 强制输入旧回答，执行原 SADI 5–18 和真实 KV 缓存。它读取所有 36 层的 risk、I、E_l，共 108 维。risk 沿用 K=32、tau=0.03、cost 与惩罚项系数均为 1 的实现。语义概率使用实际 prefill 的视觉 hpre、最终 norm 和完整词表分母，每图每层首次需要时计算一次。

同样的 8 图、31 目标按相同视觉跨度分为 4 批，批次大小分别为 1、3、3、1。全部目标位置、有限性、输入哈希和计数通过检查。首个固定批次在有无采集器时，逐步末位置隐状态及最终 36 层全部 KV 的摘要精确一致。其余批次复用相同的只读采集路径，没有逐批重复此对照。纯特征路径每批只有一次视觉前向，控制实验另计一次。

四批特征路径及首批对照共用时约 104 秒；31 个目标共解 1,116 个风险输运问题。输出仅保留特征、目标行号和计数，不保存隐状态、注意力矩阵或完整 logits。预检特征 SHA256：`817a075d4e978d547a5094276d7ad141352ed19e7119fca5a32226474020d553`。

通过后启动了两卡源特征刷新：3,948 图、11,751 个目标、276 个预先固定批次，最大 batch=16，两卡各 138 批。源标签与原 3,200/800 图片划分不变。这里强制输入的是旧原始模型回答，不能称为新生成的 SADI 描述。本报告定稿时尚未训练新探针，也没有占用独立 500 图。
