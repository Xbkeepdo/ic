# Qwen3：SVAR＋首次类别19层引导的全新500图验证

固定候选在第三批独立500图上降低了标准sentence-CHAIR，并提高了测得的物体F1。相对SVAR，CHAIRs下降2.60pp、CHAIRi下降0.6768pp、F1提高0.4928pp。逐图复核同时发现，18张自动CHAIRs消除中14张涉及词义、部件或语境边界，另外4张尚不能确认真实纠正。因此数字改善可以复现，但不能表述为18张真实物体幻觉被消除。

## 固定方法与设置

模型Qwen3-VL-8B-Instruct，BF16/eager/greedy，相同提示Describe this image.，cap512、maxB16、两卡分片；所有层号从0开始。三臂分别为原生SADI参考、原生SVAR、SVAR＋原候选。三臂均新生成，64个实际有序批次完全相同，无OOM分裂。

SVAR作用于5–18层，保持项目原BF16原地算子。候选只在19层回收部分正向支持原目标的生成历史注意力，转给梯度判为负向视觉写入的位置。原72维I/E_l检测器p_real<.5、309词形、前缀首次类别、FFN空间偏好及rho=.5D保持不变。以最终目标概率梯度确定写入方向，实际原目标概率下降才保留；重算当前查询20–35层并维护当前KV。未叠加后续FFN正增益门控，也未重新训练。

该方案使用原诊断框架的I/E_l和视觉写入／FFN空间偏好组件，不是完整SAM/SAM-V2，也不是精确K32 OT风险的在线实现。与旧18→19／19→20相邻层方案不同，当前源与动作均为19层。

抽样seed20261121，样本SHA `961288b742687f3915b1e2beb49d1da9eaa98c1682a21bbf22557d324b4b4b65`。从40,504张val2014中排除7,850张，候选池32,654；与旧训练3,948张、开发100和前两批独立500均零重叠。算法在本批测试前固定，旧100有词义归类问题的发现不触发本批参数修改。

## 逐图复核

`lexical_case_review.json`覆盖全部18消除／5新增及两项额外大幅提及变化，附原文、标签、输入SHA及看图标记；保存了原评分，未删图或改评估器。它不是全体CHAIRi提及变化的穷尽人工审核。

14项自动消除有明确语境或类别边界，包括orange颜色、giraffe calf、goat cheese、skateboard trucks／skatepark bowl、remote形容词、拍照设备推测、沙发／浴室seat以及train改写为subway car等。4项余下案例是远处clock tower、餐桌小bowls、杂食自助餐的banana/cake以及手中小物体phone；已看图，但无法可靠确认对应物体缺失。

最大提及变化577036还涉及车身riverboat图案、自行车taxi、座椅部件及车顶黄色篷；后文改成可能的paddle也不准确。281827的container是楼顶储罐，passenger修饰飞机。这些例子说明当前自动得分与真实物体纠正不能直接等同。这里不根据这部分人工复核推断全部CHAIRi变化都是归类误差。

因此保留此配方作为标准指标改善的探索性结果；后续需要验证风险／偏好信号相对不看特征的匹配门控是否有额外作用，并解决在线目标的语境适用性。SADI参考在本批上的CHAIR仍低于增强SVAR，当前结果不代表同一方案在不同基底上均有稳定收益。
