# Qwen3 批次敏感性：首次 token 分歧诊断

2026-11-17，500 图单图生成结束后，在同一 GPU1 对 COCO 图 485532 复验。该图在此前独立 100 图任务中属于 B2 批次 `[485532, 558955]`，在后来的 500 图任务中属于 B4 批次 `[206591, 276437, 485532, 558955]`。两批每张图均有 240 个视觉 token。

本次仅回放共同首 token `1986`，检查第二个生成 token。使用原生 `generate` 和 KV cache，保留原始 512 token 上限，用停止条件在第二步结束。每行回放自己的缓存前缀，并检查施加强制之前的贪心选择是否与缓存一致。SVAR 和 SVAR＋SAR/EMS 分别运行；每种方法增加原生 B1、批量控制器 B1、B4 行逆序和 B1 重复对照。没有重新生成整段描述。

## 已复现的分歧

两种方法的关键结果完全相同：

| 条件 | ` image`（2168）logit | ` is`（374）logit | 实际贪心 token | 是否复现对应原批次缓存分支 |
|---|---:|---:|---|---|
| 原 B2 | 37.00 | 36.75 | ` image` | 是 |
| 原 B4 | 36.75 | 36.75 | ` is` | 是 |
| B4 行逆序 | 36.75 | 36.75 | ` is` | 是 |
| 原生 B1 | 36.75 | 36.75 | ` is` | 不同于作为参考的旧 B2 token |
| 批量控制器 B1 | 36.75 | 36.75 | ` is` | 同上 |
| 原生 B1 重复 | 36.75 | 36.75 | ` is` | 同上 |

原 B2、B4 的 `cached_branch_reproduced` 均为 true，所有批次行的此前未强制 argmax 都与缓存前缀一致。因此这次复现了原来观察到的分歧，而非只在人工前缀上制造不同输出。B1 的 false 是因为其检查目标仍是旧 B2 的 token 2168；B1 自身重复运行完全一致，不代表 B1 重复性失败。

B2 的两词间距为 0.25；B4 中两词并列最大，实际 `argmax` 选取 374。B2 与 B4 的全词表原始 logits 最大绝对差为 0.4375，平均绝对差为 0.0617738。处理前和处理后的 logits 对本例给出相同结果。SAR/EMS 增强版在探测步没有后层引导目标；SVAR 基底本身也重现该分歧。

## 差异出现的位置及对照

- 进入第 0 个语言解码层之前，同一图片的视觉输入表示已经不同：最大绝对差 0.609375，平均绝对差 0.0104743。最后一个文本输入向量完全一致。这一差异早于第 5–18 层 SVAR 干预及第 21、22 层 SAR/EMS 干预。
- 原生 B1 与批量控制器 B1：所有已捕获张量逐元素相同，包括视觉输入、选定层输出、最终 logits。
- B4 与 B4 行逆序：所有已捕获张量逐元素相同。
- B1 与重复 B1：所有已捕获张量逐元素相同。

因此本例已证实：改变批次后，同一图的视觉表示与最终数值发生变化，接近并列的词表决策随之切换。该变化无需 SAR/EMS 新模块即可出现。本例未发现 B1 控制器移植差异、B4 行顺序差异或 B1 重复不稳定。

## 结论范围

这是对一个图片、一个早期分歧位置、SVAR 基底及其增强版的受控诊断。可以将此分歧归为已复现的批次相关执行／数值差异；尚未定位视觉编码器或投影内部的具体算子，也没有单独改变精度、固定大小更换伴随图或重放全部 66 张。因此不能把“某个 BF16/GEMM 舍入算子是唯一根因”“没有其他实现问题”或“66 张都已逐一解释”作为结论。

此前 SADI 60 图与新增 500 图不仅推理协议不同，图片也完全不重合；60 图的 CHAIRs 改善仅对应 4 张修复、0 张新增，CHAIRi 又受单张重复幻觉影响。本次 SVAR 分歧诊断不能单独解释这两个 SADI 样本集的全部指标差异，亦不能把早期小样本有利点估计恢复为稳定的模块增益。[60 图记录](QWEN3_SADI_SAR_EMS_TRANSFER_20261116.md) · [样本与批次口径核对](QWEN3_SINGLE_BATCH_COHORT_AUDIT_20261117.md)

脚本为 `scripts/diagnose_qwen3_batch_logits.py`。服务器根目录为 `/root/rivermind-data/ic-ac/outputs/qwen3_batch_logit_diagnostic/`，两个子目录为 `485532_svar/` 和 `485532_svar_sar_ems_attention/`，各含 `plan.json`、`report.json`、`probe_tensors.pt`。运行环境记录为 RTX 4080 SUPER、PyTorch 2.12.1+cu130、CUDA 13.0、TF32 matmul 关闭；模型按项目 BF16 配置加载。队列两任务退出码均为 0。
