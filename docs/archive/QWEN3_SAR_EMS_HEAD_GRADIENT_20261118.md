# Qwen3 逐注意力头的目标梯度与 FFN 空间偏离

本轮检验共享空间预算的干预方向。前一版在各头上加同一个视觉位置预算，即使某些头在同一位置写入相反的目标词证据，也会一起改变。新版本按各头实际写入对最终候选词的影响决定正负方向，并用目标视觉支持和 FFN 空间偏离控制幅度。

## 两个实验版本

保留 SADI 5–18 层、当前最终候选词为未出现过的实体、第 31 层局部视觉支持 $V_y<0.35$ 的门控。层号从 0 开始。跳过 prefill。两组都调整第 31 层注意力，再重算 31–35 层的当前查询。

源层梯度版以第 31 层 FFN 后的目标词 log probability 为目标，求它对该层 FFN 前残差的梯度。最终梯度版继续经过第 32–35 层，以最终目标词 log probability 求梯度。后者通过只读的前缀 KV 做一次当前查询尾部前向和反向；模型参数冻结。两组的目标词身份都来自常规前向的最终候选。

令 $g$ 为上述梯度，$c_{hm}=g^\top W_{O,h}v_{hm}$，$A_{hm}$ 为实际视觉注意力权重，$\bar c_h=\sum_m A_{hm}c_{hm}/\sum_m A_{hm}$。保持各头视觉总注意力权重时，对视觉 logits 的局部导数为 $d_{hm}=A_{hm}(c_{hm}-\bar c_h)$。

按负向贡献 $\sum_h[-A_{hm}c_{hm}]_+$ 构造归一化位置分布 $Q_-$。保留 FFN 更新对视觉状态的余弦偏好 $P=\operatorname{softmax}(\cos(u,h_m)/0.03)$，以及平方 Hellinger 偏离。设 $\rho_-$ 为负向贡献绝对值占全部正负贡献绝对值的比例。给每个头与位置单独的 logits 调整。

$$
\Delta s_{hm}=-3H^2(Q_-,P)\,\rho_-\,\tanh(0.35-V_y)
\frac{d_{hm}}{\max_{h',j}|d_{h'j}|}
\left(0.25+0.75\frac{[Q_-(m)-P(m)]_+}{\max_j[Q_-(j)-P(j)]_+}\right).
$$

加入后通过各头视觉 logits 的 log-sum-exp 修正保留视觉总权重。梯度内积的一阶预测为非正，但 BF16 和有限步长下实际概率可能上升。先前两图预检的 13 次提案中，最终梯度只有 6 次实际下降。因此新版本对重算后的真实最终概率进行检查，只保留下降的行。其余行恢复原 hidden state 和第 32–35 层当前 KV。前缀 KV 保留，目标判断和接受过程不读取物体标注。

## 缓存检测器的补充检查

继续复用旧 COCO4000 紧凑缓存。将两层选择放入训练图片的三折内部，比较 risk/F_log 与 I/E_l 两个家族。按交叉预测的同 token AUROC 选中 risk/F_log；全训练集选择第 27/28 层，共四个输入。训练交叉预测 AUROC 0.744、同 token 0.750，原测试分别 0.776、0.746。用训练交叉预测真实分数的95分位作阈值，原测试真实误触发 4.65%、幻觉召回 27.75%。参数和分析在 `scripts/experiment_snapshots/qwen3_selected_layer_cached_gate/`。仍需检查在 SADI 生成上的迁移。

另直接加载用户原来的 seed43 checkpoint 和 scaler，使用完整逐层特征重算旧测试集，AUROC 与记录逐值一致。I/E_l 为 0.9018、同 token 0.7738，risk/F_log 为 0.9019、同 token 0.7905，risk/I/E_l 为 0.9111、同 token 0.8035。无需重新训练这些检测器，记录 `full_detector_cache_audit.json` 保存路径和哈希。

后续若尝试完整 I/E_l 门控，可在 prefill 把每层视觉位置的语义概率按位置求和，保留每个词一个 E_l 标量；36 层、B16、152k词表的 FP32 缓存约350MB。当前查询的 I 可从原生 KV 的视觉 value 和实际注意力行计算，不必额外保存所有层的重复 KV 或完整视觉词表矩阵。实现前应核对紧凑缓存的 E_l 归约定义，并用直接特征函数检查数值。
