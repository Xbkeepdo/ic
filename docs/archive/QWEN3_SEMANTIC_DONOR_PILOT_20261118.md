# 完整 SADI 后的语义支持与注意力转移实验

本轮保留完整 SADI 第5–18层，在后续第19层比较两种注意力转移。层号从0开始。使用旧开发集100图、原22个有序批次、最大batch16、相同提示词和512新token上限。SADI、旧I/E_l指导第19层及SVAR控制直接复用冻结输出；本轮仅生成两个新版本。开发集上的结果用于筛选方法。

## 门控与两种干预

两组使用相同的原108维SAM-V2，输入为36层risk、36层I及36层E_l。risk采用原K32、tau=0.03、cosine cost及两端点惩罚系数均为1的精确EMD。读取实际轨迹，不使用局部编辑前的注意力。门控阈值为0.418672114610672，由旧域783图、1848个真实目标的真实概率第5百分位得到。候选须是在线最终argmax的已知物体词首token，并且该token及其物体类别此前未在生成文本中出现。

单独更换SAM-V2门控在此前诊断中产生17个真实位置误触发，未通过预定上限。这里测试新的门控与注意力联合策略，不改变或重写此前门控诊断结论。

历史转移对照使用原来的负视觉梯度证据与FFN偏好Hellinger漂移D，预算比例为0.5D。从对当前目标具有正贡献的生成历史位置回收注意力，转给具有负贡献的视觉位置，并沿用FFN偏好缺口调整接收分布。

语义支持版本额外计算每个视觉位置对当前类别的支持：

`S_j = [max_alias p_j(alias) / max_309 p_j(object)] × [V max_alias p_j(alias) / (1 + V max_alias p_j(alias))]`。

这里的p来自视觉hpre经final norm后的完整词表概率，类别别名共享支持。写入支持缺口`U=sum_j Normalize(||W_j||) (1-S_j)`由实际视觉写入范数加权；全零写入时U=1。该组预算比例为0.5DU，同时允许从对目标有正贡献、但语义支持不足的视觉位置回收注意力，回收比例再乘1-S_j。接收分布与历史对照相同。

两组都仅在原目标的实际最终log概率严格下降时保留干预，否则恢复hidden及第20–35层当前KV。过去位置的KV保持不变。模型参数冻结；使用一个目标梯度，不进行权重训练。

## 成本复用与实现校验

每图每层的309列完整归一化概率按需计算，图像位置分块64；同一有序组内两组共享概率缓存，首次复用须精确核对hpre、GQA value、token及输出权重标识。risk和I依赖当前生成轨迹，每个候选重新计算。仅保存描述、标量事件和统计，不保存hidden、attention或完整词表张量。

CPU原型检查通过历史对照逐值旧公式、质量守恒、非负、充分支持零动作、无反证零动作、视觉独立供体及逐头剂量匹配置换。GPU修正版预检在2图32token上通过：risk和I逐值等于此前完整读取器，E_l在3e-6相对误差内，模型概率差为0；读取、禁用、零预算及全部拒绝时，tokens、logits与全部36层当前KV均精确原SADI。真实干预两组均产生并保留提案，梯度重放hidden最大差0，静态缓存复用检查通过。每次生成仅一次图像编码。

首版GPU预检因移除诊断读出后未显式初始化FP32输出投影缓存而以KeyError(19)结束，未启动100图。失败日志、请求SHA及源码保留；修正版使用独立preflight_v2目录。

## 逐图及分母检查

历史版的3次自动减错分别来自19132的颜色orange变为reddish-orange、243882仍存在的虚构table从13次变12次，以及316254删除“phone or remote control”中的遥控器备选。复核316254可见折叠手机，删除不支持的备选有局部作用，但仍有虚构table，不能解释为消除一张幻觉图。243882的书由人拿着，桌子错误仍在。

语义版也改变19132颜色写法；176034的train station是场所短语，新计入的people来自“does not contain any people or animals”，是明确否定句；555298的girl变child，对应同一张可见照片。这些变化均保留原评估输出，不自行改标签。353411在两版中仍把餐巾上的勺子写为叉子；降低原候选概率没有纠正该错误。

两版真实图像类别数都保持204，重复真实提及从828增至892／872。因此CHAIRi下降部分来自分母增加。移除各自真实重复增幅最大的3图后，历史版CHAIRi为7.77%（相应SADI7.97%）；语义版为7.02%（相应SADI6.92%）。新增语义转移未获得稳定改善，本轮不把它作为有效候选。
