## 方法范围

旧COCO完整I/E_l检测器输入为36层I及36层E_l，固定`p_real<0.5`。I在5–18层读取局部SADI分数编辑前的注意力，实际残差仍受SADI影响，不是完整无SADI反事实。E_l在SADI图像预填充时缓存，按相同有序批次复用。

当前最终贪心词须属于固定309个单token物体词形，且其类别未在实际生成前缀出现。此范围没有确认后续词边界或词性，仍有颜色和复合词误命中。

计算最终目标log概率对19层注意力后残差的梯度，得到目标条件视觉贡献；读取实际19层FFN更新的视觉空间偏好。二者Hellinger偏离D控制回收比例`0.5D`，从支持目标的已生成文本位置移出部分注意力，分给反对目标的视觉位置，方向额外使用两种空间分布的差异。保留提示词路线，FP32下每头总质量守恒。只保留使原目标实际最终log概率下降的提案，否则恢复隐藏状态和当前KV；下降不保证替换正确，提案可能不立即改变argmax但影响后续状态。

正式实验不强制触发，不重新训练或按新500调阈值。它使用I/E_l及视觉写入／FFN关系，不等同于完整SAM、SAM-V2或精确OT risk。
