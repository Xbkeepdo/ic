# Qwen3 SADI next-layer guidance: new300 and pooled500, max256

日期：2026-11-17。用户说明另一服务器500图是相对同批SADI变差，并要求补跑300。本轮保持最近的下一层配方，不调参。

## 结论

修正分词口径下，新300及合并500的CHAIR点估计均下降，召回/F1略降；两组样本的四项指标95%配对区间均跨零，尚不能宣称稳定或显著改善。新300的幻觉提及净减少37次中，34次来自两张图；合并500的净减少43次中，41次来自三张图。收益仍受少数重复物体提及影响。旧口径下新300的CHAIRi反而上升，合并500仅略降。

这不能证明用户另一服务器的500图存在操作错误，也不能证明硬件是原因；其命令、图片清单、真实批次和评估版本尚未取得。本次是独立扩展实验，不是对该另一服务器运行的严格复现。

## 固定协议与样本

- Qwen3-VL-8B-Instruct；SADI零起层5–18。
- 下一层反馈：本层18的Q/P指导注意力19，本层19的新Q/P指导注意力20；strength5、tau0.03、WordNet entity首子词和positive FFN gain门控保持不变。
- BF16、eager attention、greedy；prompt为`Describe this image.`；两组均最多256个新token；max batch16，两卡各150图。
- 实际按视觉token跨度和prompt长度分桶；保留尾批，两组有序batch完全相同；43个batch/方法，其中11个B16覆盖176图；无OOM、重试或Traceback。
- 40,504可用图中排除5,550张历史图，从34,954候选以PCG64 seed43抽300；与10个历史来源及旧200均零重合，诊断图也已排除。
- 新300 IDs SHA256：`53d79bdb6f8a46b4662aeffddef74db09cfd080e08068624f9502ff42e91a552`；合并500 SHA256：`2df95828676a19b18e9807dd57cc55d3f8ac774f97e0e96454ba14d24cefef26`。
- 27源码/config哈希预先冻结，本地与服务器规范文本一致；复用先前通过的13项相同推理源码/config GPU验证，未重复加载模型做额外GPU测试。未宣称完整权重逐文件哈希审计。
- 合并500为**已观察200＋新300**，不是500张全部首次验证，也不是重新整体按500分批生成。原200的400条描述、原始batch及字节保持不变；合并存为旧0/1、新2/3四分片/方法。

## 重复提及与评估差异

图377620：GT为bear/teddy bear。SADI重复写`hospital bed.`，sentence统计25次bed；增强版仍写1次bed，并转为重复bandage/foot句子，两组均达到256。旧整段Treebank漏掉中间句末的`bed.`，于是旧口径两组均只统计1次bed。增强版减少了重复错误物体提及，**并未消除该图的生成循环**。

图532552：按本评估GT，SADI的baseball glove有10次幻觉提及、增强版0次；这些主要是句末`glove.`，旧口径均漏计。GT仍为baseball bat/person/sports ball，未进行人工图像重新标注。不得把CHAIR标签直接等同于人工确认物体绝对不存在。
