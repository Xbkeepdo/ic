## 方法

保持本仓库已有SADI实现的第5–18层干预，在第19–35层加入联合注意力输出调整，所有层号从0开始。目标是当前原生最终logits的argmax词元。门控使用既有108维SAM-V2检测器，输入依次为36层risk、36层I和36层E_l；阈值0.418672114610672由此前来源中的real位置校准，保持不变。仅考虑既有309个词首词元及生成前缀尚未出现的物体类别。原risk配置保持K=32、tau=0.03，cost和两端点惩罚系数均为1。

注意力方向借鉴[ACG](https://arxiv.org/html/2601.13707v2)：在同一原生Q/K/V下，计算含图上下文与屏蔽视觉键后的上下文之差，再去掉其平行于屏蔽路径输出的分量，得到每头方向d。固定版在17个层的全部注意力头上使用gamma=1.4。

指导版根据目标条件视觉写入和FFN视觉偏好的差异分配尺度。令rho为各视觉位置实际写入向量的范数，p为对应视觉hpre经final norm和完整词表softmax后对当前目标y的概率：

```text
log_s_lj(y) = log(1 + V * p_lj(y))
Q_l        = Norm(rho_lj * (1 + log_s_lj(y)))
P_l        = softmax_j(cos(u_FFN,l, hpre_visual,lj) / 0.03)
D_l        = clamp(1 - sum_j sqrt(Q_lj * P_lj), 0, 1)
e_lh       = (g_A,l^T W_O,lh) d_lh
gamma_lh   = 1.4 * D_l * relu(-e_lh) / max_h relu(-e_lh)
```

其中g_A为原目标最终log概率对注意力后残差的梯度；若某层所有e非负，该层尺度为0。视觉写入范数从原108维特征计算中直接复用。固定和指导版共享经过图像前缀逐值核对的静态语义缓存，保存在RAM中。固定版先运行并承担共享初始化时间，因此两版耗时不能直接解释为各自固有速度。

17层方向与预算在同一个原生解码点计算。指导版只进行一次联合反传，得到所有层的梯度。联合回放中，第19层复用原Q/K/V，第20–35层根据修改后的上游状态重新计算当前Q/K/V，并加入各层预定的原生方向增量。预算没有逐层刷新。仅当原目标的实际最终log概率下降时保留，否则恢复原隐藏状态和当前KV；过去KV保持不变。门控、作用层、头尺度、联合回放与接受规则是当前适配的设置。

## 终局检查与结论

完整事件/层尺度、独立指标及配对区间、分母重复三项CPU审计首次均通过。旧案例格式化脚本错误地要求无梯度固定版提供梯度预测字段，第四步报KeyError。原脚本、错误日志、失败状态和全部原始输出均保留，新增v2格式化脚本只允许固定版该字段为null；指导版和其他字段仍严格检查。448条完整事件验证后，复用前三项审计，仅重新执行CPU案例分析并通过，未重新生成任何描述。恢复协议记录了被读取的旧状态版本。

固定筛选要求两项CHAIR与错误提及下降、F1和召回损失在限值内、移除最大减错图后CHAIRi仍不差。两版均未通过：指导版CHAIRi与错误提及上升；固定版对最大词义/重复样本敏感。不能将本批作为稳定缓解收益证据，也不应以共同未达上限子集替换全量结果。

事后方向诊断复用已记录的155个首次原生提案梯度：82个在完整视觉方向上的一阶预测为正，筛选负梯度头后变负；66个同原生点的固定提案实际提高目标概率，而指导提案降低。该现象提示逐头抑制可能反转整体视觉方向，并放大检测器误报；梯度符号不等于词的真实性。

后续仅在旧开发100图检验更简单的方案：保留完整视觉方向，以SAR/FFN偏离D调节同层全部头的共同强度1.4D，不使用负梯度头筛选，并在完整SADI和SVAR基础上对照。新候选若通过开发筛选与原图检查，须使用另一批独立500图，不将当前500图再次当作未见测试。
