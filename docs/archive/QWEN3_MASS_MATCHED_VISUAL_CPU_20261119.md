# 保持视觉总注意力的信号引导：CPU原型

本原型在上一候选的独立500图冻结后另行开发，不改变该实验。CPU和B2/B16真实模型预检均已完成；随后启动原生来源、逐层刷新和空间打乱三个版本的旧100图开发比较，尚无新缓解分数。

旧100图中三种预算的平均增强强度不同。例如243882的book步骤，固定系数为0.5，原生和刷新预算的16层平均系数分别为0.0957和0.0466。因此原比较同时改变了空间引导与总增强强度，不能单凭结果判断哪一个因素主导。

新原型保留固定0.5增强的逐头视觉总注意力，在视觉patch之间用目标条件下的视觉写入证据Q和FFN视觉偏好P重新分配。定义

\[
D=1-\sum_j\sqrt{Q_jP_j},\qquad
r_j=D\left(2\frac{Q_j}{Q_j+P_j}-1\right),\qquad
c_{hj}=\operatorname{sigmoid}(r_j+b_h).
\]

针对实际目标层的视觉logit z_hj，为每个头选择b_h，满足

\[
\sum_j\exp\{z_{hj}+|z_{hj}|c_{hj}\}
=\sum_j\exp\{z_{hj}+0.5|z_{hj}|\}.
\]

非视觉logit不变，因此FP32下的逐头视觉总注意力和非视觉概率与固定增强相同，差别主要是视觉区域内的分布。Q相对P更高的patch获得较大的增强系数；D控制重新分配的程度。系数始终在[0,1]内。D=0或r在patch间为常量时，精确退回固定0.5增强。

匹配在各版本当前层的实际query上进行，参考是这个相同状态下的局部固定0.5操作。干预后下一层的query会改变，因此不要求不同版本整条生成轨迹的视觉总量逐层相等。真实模型中只有常量方向对照应与固定版完整轨迹精确一致；一般方向引导的后续变化属于其作用结果。

32次有界二分求解只涉及小型张量运算，无反向传播。系数求解完成后，只需一次真实softmax@V。下文先记录CPU阶段的检查，随后记录解码器集成预检；完整生成开销在开发100图中统计。

CPU检查已通过：

- FP32视觉注意力总量最大差2.38e−7，非视觉概率最大差1.19e−7。
- 从FP32概率转BF16后，本次测试的视觉总量最大差0.001129；FP32匹配不表示BF16求和严格相同。
- 零/常量方向精确等于固定增强，未选行与输入不变，逆序选行结果精确一致。
- 双patch例子中，证据方向翻转会反转区域内的移动；全零logit使用统一系数。

CPU阶段只检查算子的数学与数值性质。之后的GPU预检在上一轮500图释放资源后完成，检查包括无干预/强制拒绝恢复SADI、常量方向恢复固定增强、历史KV不变、原108输入一致，以及真实源层刷新。

算子代码为`features/qwen3_mass_matched_visual.py`，检查脚本为`scripts/verify_qwen3_mass_matched_visual.py`。CPU请求、源码快照、日志与结果保存在`scripts/experiment_snapshots/qwen3_mass_matched_visual_cpu`。解码器适配另存`features/qwen3_mass_matched_feedback.py`，继承已有相邻层KV回放和原108门控，支持原生/刷新来源及半周期patch置换控制。适配器随后通过下述真实模型检查；CPU阶段本身不提供这些结论。

适配器中一次softmax@V用于真实输出，另一次参考softmax只记录FP32/BF16质量误差，不计算参考@V。后续检查须记录实际开销。不改已通过CPU检查的两份源文件，也不改当前500图冻结的358个输入。新原型的未来独立500已在其开发100图开始前另行预留，seed2026111903；不能复用上一候选已消费的500作新方法独立验证。
