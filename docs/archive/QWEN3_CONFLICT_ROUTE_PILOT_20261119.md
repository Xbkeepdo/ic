# 完整SADI后的CRG式文本路线抑制：100图结果

信号排序版的CHAIRi从SADI的7.93934%降至2.88889%，CHAIRs从30%降至18%；物体F1同时从74.94975%降至71.60862%，召回从70.59603%降至66.07937%。相对VRI规则，CHAIRi大降但CHAIRs高1pp。原图和重复检查未支持将该强配方推进独立500图。

## 设置与方法

Qwen3-VL-8B-Instruct，完整SADI0-based5–18层；后续19–35层加入路线抑制。旧开发100图、同一22有序组、maxB16、512新token、Describe this image.、BF16/eager/greedy、两4080SUPER。三新臂各完整新生成100图，SADI/SVAR/旧fixed仅按字节复用同设置对照。新门控取消学习检测器，旧9图无阳性缓存证书不适用。

本轮借用[CRG](https://arxiv.org/html/2605.24024v1)的有符号视觉/文本路线分解，仅在视觉反对当前候选、文本支持候选的头中抑制文本。VRI版按视觉依赖排序；信号版以SAR的目标条件视觉写入Q和EMS的FFN偏好P，计算每头条件视觉分布在P/(Q+P)上的权重并排序。错位版移动该风险分数16/32头。最多8头，文本系数线性0到0.5，其余1。动作不重分配视觉权重，只缩减实际当前query的文本写入。

各层头选择在同一native点固定，一次梯度供17层共用；重放使用每层实际文本路线。该实现是CRG Conflict-B的工程适配，不是论文完整复现，不是逐层刷新next版本。三规则只在同一个局部冲突集上匹配系数多重集，不匹配后续全轨迹剂量。我们的Q/P是信号中间分布，不是原32点精确OT risk。只有原最终目标实际log概率下降才接受，否则恢复hidden及current20–35KV；历史KV保持。完整公式、原文差别、预检和冻结SHA见QWEN3_CONFLICT_ROUTE_PREFLIGHT_20261119.md。

## 重复、词义和内容损失

信号版对VRI少77次自动错误，其中76次是重复错误计数减少；对错位少50次，其中47次属于重复。并非纯分母膨胀：signal总提及900，VRI1002、roll1003。但少重复并不自动等于新的物体身份纠正。

VRI→signal最大三图变化为369675的car56→3、154497的seat/tie18→1、42182的stool/chair4→0。这三图合计74次，占77次净减少的96.10%。火车car指车厢、seat可指坐姿或真实长凳、red stool实际存在。signal还漏掉42182的真实炉灶/钟。排除三图后VRI的CHAIRi2.99401%、signal2.62530%，CHAIRs14/97→16/97；不构成全面优势。

roll→signal最大三图为154497、189305、42182，共净少51次，超过全量净减少50次。排除这三图后，CHAIRi从roll2.61661%变为signal2.84360%，两组都是16张自动幻觉图。主要增量对重复样本敏感。

相对SADI，前三图369675、243882、152336贡献47/63次净标签减少。243882的无支持table循环及353411的fork有图像支持，但三个路线规则都能减少它们。signal保留了243882更多真实物体，且避免VRI在575293中的长重复；这些是局部的内容保持收益，尚未抵消总体损失。

349642中三版都陷入wooden连续循环，真实狗与长凳没写出，召回1→1/3。377003真实扶手椅、沙发等丢失，召回.75→.25；152336的pizza改flatbread并删去细节，召回.6→.2。原图显示这些损失有实际内容依据。72935新增的红盖bottle确实存在，268363毛绒熊也存在，两张新增自动幻觉图不是已确认的物理捏造。
