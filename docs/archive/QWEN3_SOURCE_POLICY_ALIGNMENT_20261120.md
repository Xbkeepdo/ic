# Qwen3：完整SADI下的源词范围与条件预测核查

本轮检查门控校准与源目标词是否贴近实际生成时的使用条件。限定校准词表没有改善已核实错误的覆盖；两个固定源批次中，开启SADI改变了部分目标位置的首选词。没有新生成描述，也没有新的CHAIR、物体召回或F1结果。独立500图未使用。

## 保留完整SADI的主线

按用户要求，主线保留当前仓库SADI的0基5–18层，在后续层加入信号指导。截短SADI后再用我们的方法补上其他层，仅保留为消融。后续层范围的比较应固定SADI本身，并分别记录每层强度与累计干预量，避免把扩大层数和加大总强度混为一个变化。

此前同一批500图、256-token设置下，完整SADI的CHAIRs为24.40%，截短5–12层后为42.00%，再加12→13至17→18的引导为43.80%。这组结果支持保留完整基底，但不等价于对所有后续层方案的比较。详见[截短SADI与六层相邻引导](QWEN3_SADI_EXPANDED_NEXT500_T256_B32_20261117.md)。

## 同一源前缀的原模型与SADI预测

固定最早的两个源B16批次，共32张图、101个已存目标位置。模型为Qwen3-VL-8B-Instruct，BF16、eager；逐token输入原始归档描述前缀，使用真实KV。在指定目标位置才计算完整输出头，不重复生成描述。一个分支保留完整SADI5–18，另一个分支关闭SADI。两者图片、批次、提示、前缀与目标位置相同。

82个位置在两个分支中都与源词相同，5个位置在两个分支中都不同；没有原模型不同而SADI变回源词的位置。原模型与SADI的首选词共17个位置不同。源词进入当前分布top5的数量分别为101和99。

这些是同一强制前缀下的条件预测，不是新的SADI生成轨迹。词形改变可以是同类表达，也可能是同分数候选的次序改变；原词标签不能直接赋给替代词。当前未修改模型也有5处不完全复现旧源词，因此不能把所有偏差都归因于SADI。两个固定批次显示存在源策略错配，但没有证明它是门控失败的主要原因，也不能据此推断全量比例或缓解效果。

SADI分支每批复算一个108维源特征锚点，均与已封存完整源数据精确相同，最大绝对与相对误差均为0。未修改模型分支不复算特征，明确没有该数值锚点。两分支每批视觉编码器调用均为1，所有输入哈希与目标身份核查通过。

SADI两卡worker耗时40.29／36.27秒；原模型为29.29／30.68秒。两管线均返回0／0，父子进程已退出，两卡空闲。这里不计模型加载为特征计算耗时。

## 后续方向

继续保留完整SADI，将改进作用在其后的注意力层。下一项低成本检查优先寻找已有、保存了精确批次的SADI描述，以其自身生成前缀和实际候选词建立源数据；先核对与当前开发集及预留500图的隔离，再决定是否提取特征。这样可以检验源策略错配，无需重新生成已有描述。

若继续比较作用层数，应固定完整SADI和候选策略，先比较少量后续层与更多后续层，并另做总强度配平。当前源核查没有给出后续层数的最优选择。
