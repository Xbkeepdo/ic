# Qwen3：原生SADI源特征适配与词内平衡

本轮完成了源特征刷新、两组三种子的探针训练，以及两种不重训网络的对照。缓存位置的整体分类AUC有所提高，但已核实物理错误的覆盖没有改善，所有主候选均未通过预先固定的小实验筛选。本轮没有新生成描述，也没有新的CHAIRs、CHAIRi、召回或F1结果。独立500图未使用。

## 源数据与固定设置

Qwen3-VL-8B-Instruct，BF16 eager，保留完整SADI的0-based5–18层。源文本沿用原始模型已有的COCO描述；读取时逐token强制输入这些token，使用SADI和真实KV缓存。原图片划分为3200/800，其中有目标的3158/790图包含9384/2367个目标，真实标签7278/1848个。源图与开发100图、预留独立500图互不重合。

共刷新3948图、11751目标的risk、I、E_l，每项36层，输入共108维。risk沿用K=32、tau=0.03，cost与惩罚项系数均为1；I使用实际视觉写入范数，E_l使用final-norm视觉hpre的词表概率。没有重复生成源描述。两卡完成276个固定批次，最大batch16，墙钟约87.6分钟；输出身份、有限性和文件哈希全部通过。特征SHA256为24775bca2fdccf43c856d0783b3124a9580d09bf77d4b04e53008629bf5594f9。

探针沿用128维单隐层、无BatchNorm、dropout0.3及原优化配置。标准化只使用源训练部分，checkpoint按最低训练损失选择。训练种子43/44/45均保留，生成候选主种子固定43。缓解触发阈值取源测试部分1848个真实目标分数的第5百分位数，该部分用于校准。源分类报告另保留原train-F1和0.5阈值结果。

## 两种不重训网络的对照

第一种保持原权重和原标准化，只用原生源特征重校准触发阈值。第二种保持原权重，改用原生源训练部分的均值与标准差，再重校准阈值。原权重文件字节相同。原标准化配方在9384个原始源训练记录上的重放误差为0；更新标准化与显式仿射映射、保存后重新加载的输出误差均为0。这两项仅做CPU计算。

## 词内平衡

普通源适配提高了整体分类AUC，同一目标token内部的排序没有提高，因此进一步检查训练词语与标签的关联。

源训练部分有496个目标token，其中205个同时有真实和幻觉标签，覆盖7956个目标。对双标签token的样本设置w_i=1/n(token_i,label_i)，其余1428个单标签目标的抽样权重为0。这样每个token的真实、幻觉总权重分别为1，期望先均匀抽token，再均匀抽标签，最后在该组内均匀抽样。tokenID只决定采样权重，不输入网络。

每个完整epoch仍抽9384次，batch256、drop_last后用9216次、36个更新；其他配置不变，标准化仍使用原9384个训练目标。三个训练loader的正、负加权质量均为205，抽样核查通过。源训练中fork有53真实、11幻觉，table有238/70，book有23/7。

## 已知错误与新增触发

图353411的餐巾上是有实例标注支持的spoon，原描述称fork。原门控分数为0.321520，低于原阈值0.418672，能够触发。普通源适配的主43分数变成0.977337，阈值0.356136；词内平衡主43分数为0.947448，阈值0.130274，均漏掉此目标。更新标准化的分数为0.974008，也漏掉。图243882的假table在普通适配主43下为0.997063，同样没有覆盖。

普通适配主43没有新增触发。更新标准化新增26611和450391的颜色orange，以及549410的真实books；词内平衡主43新增11320的真实people和8065的真实baseball。没有获得新的、经图像支持的物理错误覆盖增益。

原先固定的小实验条件是：主43仍覆盖已核实fork，同时自动真实标签上的误触发减少。本轮所有变体均未满足，相关False结果和全部种子保留。已准备的100图入口没有启动；没有通过改阈值、更换主种子或生成测试去追这个案例。

## 后续核查

当前源caption来自原始模型，特征在开启SADI并强制旧prefix时读取。此前没有保存目标处的原生argmax。下一步先在两个预先固定的源批次核对：该源词是否仍为SADI在这个强制prefix下的首选词。这个核查有助于区分源分布错配与信号本身的区分能力。

若需要更贴近实际生成的源数据，优先复用已有历史SADI描述和原批次，排除当前100及预留500，而非重生成整套数据。另一方向是直接检查有符号视觉写入对目标及近邻物体的支持，以及FFN对这些目标的偏好；先核实中间量，再设计干预。
