# Qwen3 早期优势与后续复验差异的核对

2026-11-17。用户所说“自己复跑”指最初 Qwen3 60 图结果之后，本会话内继续运行的全部实验，并非另一套外部命令。下文区分样本、推理协议及基底变化；不能把这些实验统称为完全相同设置的复跑。

## 从原 SADI 60 图开始

箭头均表示同一批图上的 SADI → SADI＋SAR/EMS 后层版。原 60 图为 Qwen3 重新生成的结果，并未复用 LLaVA 描述。

| 样本与推理 | CHAIRs ↓ | CHAIRi ↓ | 物体 F1 ↑ | 修复／新增幻觉图 |
|---|---:|---:|---:|---:|
| 原独立 60 图，单图推理 | 23.33% → 16.67% | 15.29% → 1.58% | 73.62% → 72.15% | 4／0 |
| 新增 500 图，批量推理 | 26.60% → 26.00% | 5.58% → 5.01% | 72.18% → 72.28% | 20／17 |

两批图片无重合；干预配方的记录参数相同，但代码历史有功能扩展，不能声称源码字节完全一致。扩样时还从单图改成批量，因此结果差异同时混入样本和推理设置变化，不能单独归因于图片数量。

60 图中只有 4 对图像的 CHAIRs 状态改善、0 对恶化。原普通配对 bootstrap 的区间排除零，但仅 4 对不一致样本的双侧精确 McNemar p=0.125，不足以稳健宣称显著改善。图 379162 的幻觉提及从 98 降到 0，占全量净减少 102 次中的 98 次；移除它后 CHAIRi 仍从 2.37% 降至 1.61%，但没有全量所显示的巨大降幅。

500 图修复 20 张、新增 17 张，净改善 3 张，因此 CHAIRs 仅降低 0.60 个百分点。图 537692 减少 47 次幻觉，超过全量净减少的 43 次；移除它后 CHAIRi 从 SADI 的 4.96% 变成增强版的 5.08%。共同未触顶 334 图是按生成输出筛选的敏感性子集，不能替代全量结果。

随后将模块迁移到 SVAR，又改变了基底。新完成的 SVAR 单图 500 图不是 SADI 两臂的单图复验。此前对小样本有利结果的解释过强；样本少、单图影响大、协议变化和多轮探索后的候选选择，都限制了稳定泛化的结论。当前数据没有确立模块稳定的大幅收益。

## 图片集合

此前 100 图是种子 43 原始无放回抽样顺序的前 100 张；当前阶段 100 图是同一个固定 500 图清单按图片 ID 排序后的前 100 张。两组仅重合 17 张，各有 83 张不同。此前那组 100 图在当前生成清单的位置分布为：前 100、第二个 100、第三个 100、第四个 100、第五个 100 分别有 17、18、15、24、26 张。最后一张位于第 497 个位置。

此前“100 图单独运行”指单独启动该样本集的实验，内部仍然按视觉跨度批量生成，最多 16 张同时推理；它不是 batch size 1。

## 从逐图缓存重算

表中为百分比，箭头表示 SVAR → SVAR＋SAR/EMS 后层注意力。CHAIRs/i 越低越好，F1 越高越好。

| 图片与推理协议 | CHAIRs | CHAIRi | 物体 F1 |
|---|---:|---:|---:|
| 原随机 100 图，单独组成批次 | 44.00 → 40.00 | 10.44 → 9.28 | 75.57 → 76.38 |
| 同一原随机 100 图，从 500 图批次缓存取出 | 36.00 → 40.00 | 8.66 → 9.63 | 76.75 → 76.93 |
| 同一原随机 100 图，从完成的单图 500 图缓存取出 | 42.00 → 40.00 | 9.52 → 9.74 | 75.36 → 74.80 |
| 当前生成顺序前 100 图，从 500 图批次缓存取出 | 42.00 → 48.00 | 10.06 → 10.40 | 74.79 → 73.75 |
| 同一当前前 100 图，单图推理 | 46.00 → 48.00 | 10.96 → 10.49 | 72.53 → 71.34 |

前三行图片完全相同。前两行中，66 张的实际 batch size 改变，两方法各有这 66 张的生成序列改变。第二、第四行来自同一次 500 图输出，改变的是取出的图片集合。第四、第五行图片完全相同，改变的是批量／单图推理路径；两方法各有 96 张的完整 token 序列改变，所有图片的视觉 token 数一致。旧批次中当前 100 图有 83 张位于 batch size 16、2 张位于 batch size 1，其余位于其他大小的批次。

当前同图批量→单图，SVAR 修复 5 张幻觉图、新增 9 张；增强版修复 7 张、新增 7 张。该差异在 SVAR 基底也存在，不能仅归因于新模块。

## 已确认与尚未定位

单图协议和 500 图批量扩展协议记录的 `features/qwen3_sar_ems_attention.py` 与 `features/llava_sar_ems_attention.py` 源码 SHA-256 相同。单图与批量控制器是不同入口，已有有限烟测核对，静态审查未发现明显跨图片状态混用或 batch 维归约错误。

这些证据不能证明整个批量路径正确。后续已固定图 485532 和相同文本前缀，在首次 token 分歧处复现原 B2／B4 两条路径：B2 中 ` image`／` is` 得分为 37.00／36.75，B4 中变为 36.75／36.75，实际 argmax 因并列选择 ID 较小的 ` is`。变化在进入语言第 0 层前的视觉表示已出现；原生 B1 与批量控制器 B1、重复 B1、B4 行逆序对照均一致。两方法都通过缓存分支及全批次前缀复现检查。此例支持批次相关数值差异导致贪心分支切换，尚不能把具体 BF16 算子认定为根因，或断言解释了全部 66 张。见[首次分歧诊断](QWEN3_BATCH_LOGIT_DIAGNOSTIC_20261117.md)。

早期 100 图的有利结果能从评分缓存复算，但只能作为那次批处理设置下的探索结果，不能作为稳定增益的证据。当前 500 图已按固定单图协议完成，第三行是复用输出得到的原随机 100 图同图对照：CHAIRs 改善 2 个百分点，但 CHAIRi 与 F1 均未改善。
