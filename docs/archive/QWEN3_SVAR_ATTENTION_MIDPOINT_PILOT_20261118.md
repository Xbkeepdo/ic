# Qwen3：风险引导注意力提案的两种保守更新

本实验在原 SVAR 风险引导版上比较两种注意力更新，不改变风险判断、类别门控、目标梯度或 FFN 引导。固定证据 FFN 接受实验未通过预设筛选后，转而检验较小的注意力移动是否更稳定。两臂开发 100 图已完成，四项审计通过；两项 CHAIR 点估计低于原生 SVAR，但均未优于原风险版的 CHAIRi。

原注意力为 $a$，既有方法提出 $b=a+\delta$。两臂分别为：

- **Half**：$a'=a+\delta/2$。
- **Geometric**：对每个头的已改变位置 $G=\{j:\delta_j\ne0\}$，令 $m_G=\sum_{j\in G}a_j$，取 $a'_j=m_G\sqrt{a_jb_j}/\sum_{k\in G}\sqrt{a_kb_k}$；其余位置保持原值。该分布最小化固定质量条件下的 $\mathrm{KL}(a'\Vert a)+\mathrm{KL}(a'\Vert b)$。

两种更新均保留原提案的符号和支撑：视觉中反对原目标的路由增加，生成历史中支持原目标的路由减少。提示区域及其他键保持不变。因此一阶目标对数概率变化的上界为零。日志明确保存此上界，并将原提案的数值预测标为 reference；原数值预测不能当作新提案的数值预测。最终是否保留仍以重算后的原目标实际对数概率是否下降为准。

设置为 Qwen3-VL-8B、同一开发 100 图、原 22 个有序批次与两卡分片、BF16/eager/greedy、最大 batch 16、最多 512 个新 token。原生 SVAR、原风险版和 SADI 参考的生成逐字节复用，22 个静态图像 $E_l$ 缓存复用，仅生成两臂。SVAR 基底为 0-based 5–18 层，新增干预为第 19 层，必要时重算 20–35 层。该实验仍属于开发，不是独立测试。

CPU 检查已通过：SciPy 独立最优化、路由符号、未变位置、极小质量、质量守恒及归零行剔除后的 KV 行映射。随机检查最大质量误差 $1.668\times10^{-7}$。冻结前修正了 factory 中层模式与几何模式的变量遮蔽，并增加 AST 检查；未发生由此导致的失败 GPU 实验。

GPU 预检已通过：两臂关闭、零更新和强制拒绝时，logits、token 及 20–35 层当前 KV 均精确匹配原生 SVAR。两臂 live 预检均有 2 次提案、1 次保留。拒绝和 live 的 model／源层 MLP／LM-head 次数均为 32／36／67，与父方法的拒绝参照相同；几何计算没有新增神经网络前向。这不表示相对不加模块的 SVAR 没有开销。

已对五臂 500 条描述重算两种评估器及全部配对区间，核查源码、缓存、批次、动作、门控前缀、回滚和分母，并显式以 SVAR 为主参照。两种评估器各核查 80 个有向配对指标区间。两候选全部报告。预设晋级条件为对 SVAR 两项 CHAIR 及幻觉提及严格下降，F1 损失不超过 1.5 pp、召回损失不超过 2 pp，去最大收益图后 CHAIRi 不变差，且至少有一例看图确认的真实物体纠正。
