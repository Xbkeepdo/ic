# 完整 SADI 后接信号引导的注意力头分配：100 图开发实验

本轮保留完整 SADI，在后续层用前一层的视觉写入证据与 FFN 偏好分配各头的视觉注意力。100 图上，信号引导版没有超过等局部平均视觉注意力量的均匀头版本，也未超过此前的逐 patch 固定增强。不推进预留的独立 500 图。此处是旧开发集探索结果。

## 方法与文献依据

本轮阅读 ACT、AHEAD 的原文以及 CausalLens 官方实现，关注“选择或加权注意力头”，未复现其完整方法。ACT 通过校准统计选择动态头，并以多个生成分支的 query 聚合实现语义约束；本轮不使用这两部分。[ACT 原文](https://arxiv.org/html/2604.00983)。AHEAD 使用训练得到的视觉/语言潜力分数加权头输出；本轮没有训练这类网络。[AHEAD 原文](https://aclanthology.org/2026.findings-acl.425.pdf)。CausalLens 官方代码对视觉与非视觉上下文进行头级处理；这里仅读取其实现，没有复制其算子。[官方仓库](https://github.com/jijy20/CausalLens)，核对提交 7d93bf291f8d3052926c4d058a7b4f8435ded407。其所读 Qwen 代码的部分调节量含 batch 聚合，本轮新算子显式保持图片间独立。

借用的是头选择的思路。新算子由本项目的目标条件视觉证据 Q 与 FFN 偏好 P 决定头的相对增减，不需要反向传播、额外图像编码或新训练。SADI 原始层完整保留；半层分配仅属于此前的消融。

## 固定设置

Qwen3-VL-8B-Instruct，BF16/eager/greedy；同一开发集 100 图，原有 22 个有序分组，最大 batch=16，最多 512 个新 token，提示词 Describe this image.。两张 4080 SUPER。以下层号从 0 开始：SADI 作用于 5–18，19 为起始读取层；19→20、20→21，依次到 34→35。每次重放都保持同一个最终候选目标，后续读取实际修改后的前一层。

保留原 SAM-V2 的 risk36＋I36＋E_l36 门控、seed43 模型及训练阈值 0.418672114610672，沿用首 token / 首次规范物体类别范围。最终目标的实际 log probability 下降时接受，否则恢复当前 token 的后层 hidden/KV，历史 KV 不改。

三个新版本各新生成 91 图，另外 9 图来自原门控无阳性、完整 batch 的已验证缓存；该复用只适用于本轮未变的门控范围。SADI、SVAR 和旧 fixed 三个对照逐字复用。它们的图像、批次及生成长度均与本轮一致。三个新版本在每个 batch 内依次运行并共享视觉语义缓存，时间差不用于宣称本征速度优势。

## 头分配公式

源层视觉位置 j 的证据与偏好为：

```text
Q_j = Normalize_j(write_norm_j × (1 + log_s_j(target)))
log_s_j(target) = log(1 + |V| × p_final_norm(hpre_j)[target])
P_j = softmax_j(cos(hpre_j, actual_FFN_update) / 0.03)
D = clamp(1 − Σ_j sqrt(Q_j P_j), 0, 1)
```

目标层头 h 的条件视觉分布为 a_h=softmax(z_visual,h)。以 BC(a,b)=Σ_j sqrt(a_j b_j) 定义：

```text
g_h = BC(a_h,Q) − BC(a_h,P)
r_h = D × (g_h − mean_h(g_h)) / max(max_h |g_h − mean_h(g_h)|, eps)
d0_h = 0.5 × mean_j |z_visual,hj|
d_h = d0_h + r_h + b
```

每张图片单独求 b，使 mean_h sigmoid(LSE(zV_h)−LSE(zNV_h)+d_h) 等于使用 d0_h 时的均值。使用 32 步二分求解。将 d_h 加到该头所有视觉 logits，非视觉 logits 不变。该常数偏置保持头内的条件视觉区域分布，改变头之间的视觉注意力量；匹配的是当前版本实际 query 上的局部参考均值，并不等于匹配完整生成轨迹、各头质量或上下文向量扰动范数。

均匀头版本置 r=0；引导版使用上述 r；错位对照将 r 沿 32 个头移动 16 位后，重新求相同的质量匹配。D=0、平坦分数或完全饱和时回到均匀参考。零实际干预则回到 SADI，这与均匀参考不同。

## 实现检查

CPU 独立 softmax/@V、信号反向交换、平坦/相同证据、零干预及跨图片独立性检查通过。两卡 B2/B16 真实预检通过：零重放与拒绝时，tokens、logits、36 层当前 KV 与 SADI 精确相同；均匀/平坦分数与独立参考算子精确相同；真实前层 attention/FFN hook 与历史 KV 检查通过。预检冻结 429 项输入；本地预检快照 19 项 SHA 全部一致。

正式 100 图的机制、独立数值、配对分析、分母四项审核通过。uniform / guided / roll 分别 38/37/40 次提案、各接受 18 次；活跃图均 14 张，实际输出改变 10/8/10 张，反向传播均为 0。引导版 592 层分配记录中的 FP32 平均质量误差最大 1.1921e−7，BF16 误差最大 0.00025630，条件区域分布误差最大 2.9802e−7，单头质量最大实际变化 0.170238。说明算子实际改变了头分配，数值匹配成立。

## 原图与逐图分析

原图核查覆盖全部幻觉图纠正/新增、前三个非零假提及及召回变化，以及 SADI/uniform/roll/旧 fixed 之间变化的规范幻觉类别。共 6 张原图，全部复用已核 SHA 的本机 JPEG，无新下载。原始自动标签及分数未修改。

- **68198**：原图中黄色儿童自行车可见。三种新算子都把bicycle改为tricycle，规范词表漏召回；三种均未消除futon/couch标签。不能称为视觉对象纠正。

- **243882**：原图为前景书本和手、后景人物/水面，未见所述餐桌。SADI/uniform/guided都13次table；roll18次。旧fixed为0。uniform的47总提及与guided的36总提及差别不能当作额外纠错。

- **353411**：餐盘、汉堡、玻璃罐和右侧金属杯可见；白色餐巾上可见勺子，未见叉子。uniform/guided均删除fork，roll保留fork。uniform多出的glass来自table surface is made of glass，被词表映射为cup；guided不含该词。两版均未明确描述右侧金属杯。因此guided的F1差不应解释为新删除了真实杯子。

- **404464**：雪场/单板滑雪场景真实。ski facility/snow park属场所措辞变化，不能把ski标签消失直接当作移除不存在的滑雪板。三种新算子此图输出相同。

- **519598**：木椅、桌、书架、笔记本和杯等可见。uniform/guided相同，未明确提椅子；roll与旧fixed提木椅而提高召回。这是保留真实对象的差别，非引导版优势。

- **555298**：女孩确实在墙上照片中，保留person匹配不是新的物理幻觉。uniform/guided输出精确相同，均减少自动mouse标签；不能由此证明引导头优于均匀头。桌面有小物件，单图不足以确认mouse提及是否完全无支持；roll新增bottle措辞也不在此据自动标签作物理错误定论。

引导和均匀版相对 SADI 同样少 3 次标签：fork、ski、mouse 各一次。fork 的删除符合该图可见勺子而非叉子的内容，但均匀版也完成了它；ski 涉及场所措辞；mouse 未在本轮确认为无支持对象。相对均匀版，无新增的物理物体纠正。错位版多 7 次自动幻觉提及，相对引导版为 243882 的 table 多 5 次、353411 的 fork 多 1 次、555298 的 bottle 多 1 次；仅优于错位版本不足以建立相对均匀参考的贡献。

自动 screening 依据较宽的旧规则列出 uniform/guided 可进入 500；该文件保留不改。预先登记的本轮筛选还要求信号优于均匀/错位且核查物理内容，因此 human_review 将全部候选的 advance 列为空。本轮结束后预留 seed2026111903 的独立 500 图仍未消费。
