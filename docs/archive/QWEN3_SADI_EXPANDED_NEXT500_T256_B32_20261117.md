# Qwen3：截短 SADI 与六层相邻注意力引导

在同一批 500 张 COCO 图像上，截短 SADI 到第 5–12 层使两项 CHAIR 上升。再加入第 13–18 层的相邻引导，两项 CHAIR 的点估计进一步上升。相对截短 SADI 的变化小于截短本身带来的变化。

模型为 Qwen3-VL-8B-Instruct，提示为 `Describe this image.`，BF16 eager greedy，最多生成 256 个新 token。层号从 0 开始。强化版在各源层 12–17 重新计算暂定词和预算，引导各自下一层 13–18 的末查询视觉注意力。每层强度 5，温度 0.03。源层 12 保留 SADI。其后各源使用实际经过上一层引导的状态。三臂使用此前已观察的同一批 500 个 ID，重新生成所有描述。

对应用户提出的扩层设置：SADI 覆盖 5–12 层（含两端），我们的目标层为 13–18，共六层；读取与引导配对为 12→13、13→14、14→15、15→16、16→17、17→18。预算逐层刷新。六层沿用每层强度5，累计干预强度没有与原两层配方配平。

早期已完成的 224 图上，引导相对截短基底的两项 CHAIR 略低。完整 500 图反转。224 图由批次完成顺序决定，报告以完整配对为准。由于原版与增强版同时改变了 SADI 的覆盖和引导范围，扩层的增量用截短基底做参照。

本设置未显示扩大我们模块作用范围的收益。截短 SADI 后的退化明显，而六层引导相对截短基底的变化区间均跨零。本轮保留原版 SADI 的层段，不采用该六层替换配方；关于层数本身的作用，需要在相同 SADI 层段下比较。

三臂实际 57 个有序批次完全一致。最大参数 32，11 次显存不足后同步拆批，最大实际批次 20，256 张实际在 B16 中。两卡共用时 39 分 52 秒，含预检与评分。每臂成功批次的 GPU 时间累加分别为 1121.43、1192.33、1488.93 秒。所有 500 图均触发引导，共 39,731 次逐图逐层事件，其 2,785 次暂定词与最终 token 一致。六目标层事件分别为 9137、6209、6008、5911、6814、5652。

预检在两张旧图上确认关闭引导的 logits/token 精确匹配截短 SADI，六源每步更新，KV/attention/FFN 每步执行一次，无重放。已独立核对 1500 条生成、全批次顺序、两种评估的聚合与配对区间、24 个源码哈希和六层事件。
