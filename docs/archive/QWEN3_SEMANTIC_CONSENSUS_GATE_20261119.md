# Qwen3：原始 SAM-V2 与视觉语义分数的固定融合

这次诊断没有得到值得启动生成实验的门控方案。固定融合减少了部分真实物体上的误触发，但也漏掉此前已核实的 fork 幻觉，因此未通过预先规定的小实验条件。没有生成新描述，也没有使用独立 500 图。

两个已有探针分别读取原始 108 维 risk、I、E_l，以及单独的 36 维 E_l。它们的参数保持不变。融合分数为

\[
p_C=\sigma\!\left[\tfrac12\bigl(\operatorname{logit}(p_{SAM})+\operatorname{logit}(p_{E_l})\bigr)\right],
\]

其中两个输入先裁剪到 [10⁻⁶, 1−10⁻⁶]。这是融合分数，未经后验概率校准。三个阈值均采用旧源数据中 1,848 个真实目标分数的第 5 百分位数；这些原测试样本在此用于阈值校准，不能再解释为独立阈值测试。阈值分别为 0.41867211、0.56646287、0.53554805，低于阈值时触发。
