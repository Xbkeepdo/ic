# Qwen3：保留FFN预算、移除FFN目的位置权重

本实验检验FFN偏好在当前注意力回收方法中的一个具体作用。100图组件消融已完成，相对完整风险版没有显示改善：标准Cs高1 pp，F1低0.4727 pp，区间没有支持更好的整体效果。当前500图的配方未改动。

记注意力为 $a_{hj}$、最终目标对视觉路由的梯度效应为 $c_{hj}$。逐头负写入为 $n_{hj}=[-a_{hj}c_{hj}]_+$，其逐头归一化为 $q_{hj}$；跨头归一化给出 $Q_j$。原方法以FFN偏好 $P_j$ 得到 $D=1-\sum_j\sqrt{Q_jP_j}$，回收比例 $\rho=D/2$，在支持原目标的生成历史位置移出质量 $m_h$。原视觉目的位置为

$$d_{hj}=\operatorname{Normalize}_j(q_{hj}s_j),\qquad s_j=0.25+0.75\frac{[Q_j-P_j]_+}{\max(\max_k[Q_k-P_k]_+,10^{-12})}.$$

新消融只把目的分布换成 $d_{hj}=q_{hj}$。风险门控、D、同状态下逐头移出质量、历史供体、目标梯度、概率下降接受和尾部KV处理均保留。它仍使用FFN决定移动量；不能将其解释为完全移除了FFN。不同自由生成轨迹的累计动作数和移动总量仍可能不同。

这比已有的均匀目的位置对照更直接：均匀对照还取消了目标负写入的空间选择，因此不能单独评估FFN的目的位置权重。新实现读取父方法已计算的逐头负写入分布，不重复求梯度、投影或神经网络前向。原数值一阶预测标为reference，新提案仅记录非正上界，实际概率下降仍须实测。

CPU验证已通过：一个闭式例子的更新为视觉质量[0.05,0.15]，其余预算精确不变，目标一阶对数概率变化为−0.61；随机检查最大质量误差4.098e−8；1／1e−8／1e−14／1e−24尺度、无效中间行加有效行乱序、异常后恢复包装器均通过。CPU集成中父梯度调用仍只有一次。验证产物在 `scripts/experiment_snapshots/qwen3_svar_q_destination_cpu`。这些结果不等于GPU解码一致性或缓解效果。
