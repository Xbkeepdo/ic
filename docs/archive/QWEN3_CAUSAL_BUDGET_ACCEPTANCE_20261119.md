# 旧开发100图：相同干预前历史下的接受差异

这是对已封存100图的事后分析，没有重新生成，也没有修改正在运行的独立500图设置。

只比较三个版本共同提出干预的步骤，并要求该图在任何版本中此前都没有接受过干预。仅有相同输出token并不足够：接受后即使argmax不变，hidden和KV也可能已改变。本分析同时核对token前缀、原目标词、门控概率和物体类别一致。

得到32个可比较步骤。固定、原生预算、刷新预算分别接受19、18、21次；其中立即改变token的次数为9、10、12次。刷新增加了接受次数，但旧100图的CHAIR表现仍弱于固定版本，接受更多不代表缓解效果更好。

改善最明显的243882图，在step7的当前目标是原图中真实存在的book，而不是后续不存在的table。门控p_real=0.392065，低于0.418672阈值，所以触发了干预。

| 版本 | 16层平均系数 | book的实际Δlog p | 接受 | 当前token改变 |
|---|---:|---:|---|---|
| 固定 | 0.500000 | −0.027936 | 是 | 否 |
| 原生预算 | 0.095739 | +0.000720 | 否 | 否 |
| 刷新预算 | 0.046556 | +0.005509 | 否 | 否 |

固定版接受了一个不改变book输出、但改变hidden/KV的动作，之后13次不受图像支持的table提及消失；文本仍重复描写书本并达到上限。两种证据预算都使book概率上升，按预定接受条件被拒绝，最终输出与SADI一致。刷新系数最大变化0.640580，说明并非刷新未生效。

这个个例证明不同预算会改变接受行为和后续生成轨迹，但不能证明模块准确定位了当前幻觉词。这里的book门控属于真实物体上的触发，后续table的变化是间接效果。平均系数仅用于描述，不是已分离的强度因果效应；三个预算的空间分布也不同。

脚本：`scripts/analyze_qwen3_causal_budget_acceptance.py`。结果和六份原始输入哈希：`scripts/experiment_snapshots/qwen3_causal_budget_acceptance/verification.json`。原始100图结果、源文件及评估均保持不变。
