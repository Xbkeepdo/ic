# Qwen3：新 200 图，最大 batch size 16

2026-11-17 用户要求换另一批 200 图，批量 16，查看 SVAR 与 SVAR＋SAR/EMS 后层注意力的效果。

采样在生成前完成：COCO val2014 共 40,504 图，排除已登记 COCO4000、POPE、全部 `generation_time_*/cohort.json` 图像，并集 5,050 图；从剩余 35,454 图用 NumPy PCG64 seed43 无放回抽 200 图。新图与所有登记排除来源零重合，未根据生成表现筛选。详细来源、集合及哈希见 `selection.json`。

- 模型：Qwen3-VL-8B-Instruct，BF16、greedy、512 token，`Describe this image.`。
- 方法：`svar`、`svar_sar_ems_attention`，参数沿用上一轮。
- 两卡按排序后的图片清单 stride-2 各 100 张，每卡对相同 group 依次运行两个方法。
- `--batch-size 16` 是上限；按视觉跨度与 prompt 长度分桶，保留每桶不足 16 的尾批。任一方法 OOM 时原 runner 会将该组两臂一起二分重跑；最终单独报告实际分布与 OOM 次数。
- 使用新输出根目录，不复用旧描述。已有任意描述时启动器拒绝盲目重跑，须先审计断点处的配对批次。
- 图片清单、协议、相关源码哈希均在启动前冻结。主评估验证 200 图／400 描述及两臂完整有序批次严格一致。

服务器输出根目录：`/root/rivermind-data/ic-ac/outputs/generation_time_evidence_drift_qwen3_new200_b16/`。

脚本按 `prepare.py`、`launch.py` 执行；`run.py` 启动两卡并在生成完毕后调用 `evaluate.py`。已存在清单时不要再次运行 `prepare.py`。状态、PID、日志分别保存在 `run_status.json`、`driver.pid`、`logs/`。

评估复用仓库 CHAIR 实现，针对新 200 图构建一次真值缓存；按图片进行 5,000 次配对 bootstrap，额外输出实际批次、触顶统计、共同未触顶敏感性及最大单图影响。报告全量 200 图作为主结果。

本次运行已于北京时间 2026-11-17 04:52:03 完成，从启动至评估结束约 17 分 18 秒。两臂共 400 条描述、同图同批次核验通过，无 OOM 拆分。每个方法共 37 个批次，其中 7 个批次为 16 张（112 图），其余 88 图为 1–11 张的分桶尾批。实际 B16 子集在查看评分前已决定作为补充统计；主结果仍为全部 200 图。

全量 SVAR→增强版：CHAIRs 38.50%→40.00%，CHAIRi 8.55%→8.89%，召回 74.99%→76.45%，F1 75.81%→76.50%。修复 9 张、新增 12 张，幻觉提及 131→141；配对区间均跨零。实际 B16 子集也未改善两项 CHAIR。完整结果见 [实验报告](../../../docs/archive/QWEN3_SVAR_SAR_EMS_NEW200_B16_20261117.md)。
